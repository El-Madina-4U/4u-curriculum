البنوك والمعرفات

> الطبقة المشتركة اللى بتخلى المنهج قابل لإعادة الاستخدام.
> **القاعدة:** المحتوى المتكرر يعيش فى بنك بمعرف، والجلسة بتشاور عليه.

---

## 1. أنظمة المعرفات

| البادئة | البنك | المحتوى | مثال |
| --- | --- | --- | --- |
| `UP-nn` | `bank-unplugged.md` | نشاط غير موصول تعليمى | `UP-03` كرر `4` مرات |
| `UP-M-nn` | `bank-unplugged.md` §ج | فاصل حركة | `UP-M-01` روبوت متعطل |
| `PS-<track>-nn` | `bank-parsons.md` | مسألة ترتيب بطاقات | `PS-A-04` المشى بالكوستيوم |
| `DB-<track>-nn` | `bank-debug.md` | تحدى تصحيح بخطأ واحد | `DB-A-09` الببغاء بيقف |
| `AN-<concept>` | `bank-analogies.md` | تشبيه بموجة دلالية + أمثلة | `AN-loop` |
| `SK-<track>-nn` | `skill-cards.md` | بطاقة مهارة مطبوعة | `SK-A-04` أكرر |
| `G-nnn` | `glossary.md` | مصطلح بنطقه العربى | `G-114` `forever` |

**قاعدة الترقيم:** الترقيم تسلسلى ومستمر عبر المستويات. لما تضيف مدخل جديد، خد الرقم اللى بعد آخر واحد فى البنك — **ما تعيدش استخدام رقم**.

## 2. صيغة كل بنك

### `bank-unplugged.md`
```markdown
### `UP-18` — نفس التعليمة، اتناشر وش
- **المفهوم:** التصميم — نفس «الإزاى» ينتج «إيه» مختلفة
- **المدة:** `4` دقائق
- **التجهيز:** ورقة وقلم لكل طفل
- **التنفيذ:** «ارسموا وش. `60` ثانية.» بعدها كل طفل يرفع ورقته...
- **سؤال الختام:** «...»
```
لازم يكون فيه **مدة** و**تجهيز** و**نص تنفيذ حرفى**.

### `bank-parsons.md`
```markdown
### `PS-A-11` — التأثير بيراكم
- **المفهوم:** `change` مقابل `set` عند الضغط
- **الاستخدام:** `S09`
- **البطاقات:** `when this sprite clicked` · `change color effect by 25` · [نهاية] · **مشتت:** `set color effect to 25`
- **الحل:** الإيفنت ← `change color effect by 25`
- **المشتت:** ... ونقطة النقاش: «ليه `change` مش `set`؟»
```
**عد البطاقات بدقة:** بطاقات الحل + المشتت = العدد فى الظرف. اكتب الاتنين صراحة عشان الطباعة ما تغلطش.

### `bank-debug.md`
```markdown
### `DB-A-04` — بيمشى مرة واحدة بس
- **الاستخدام:** `S05` (الجلسة `B` من `Catch the bus`)
- **المفروض:** القطة تمشى للأتوبيس.
- **بيحصل:** بتحرك رجليها فى مكانها `4` ثوانى، نطة واحدة، وتختفى.
- **الخطأ:** `move` **خارج** اللوب.
- **الاكتشاف المتوقع:** «اللوب فاضى!»
- **الدرس:** اللى جوه اللوب هو اللى بيتكرر.
```
**«بيحصل» لازم يوصف السلوك الفعلى للملف بالظبط** — دى النقطة اللى غلطنا فيها أكتر من مرة.

### `bank-analogies.md`
```markdown
### `AN-costume` — الكوستيوم
**الموجة:** فكك: «...» ← استكشف: `UP-06` ← أعد التركيب: «...»

| # | المثال | الصياغة |
| `1` | كتاب الرسوم | «ارسم على أطراف الصفحات وقلب بسرعة...» |
```

### `skill-cards.md`
```markdown
### `SK-A-06` — أغير شكله
- **متى:** أنيميشن أو تعبير.
- **الخطوات:** تاب `Costumes` ← ارسم أو اختار ← فى الكود: `next costume`.
```
**نص البطاقة على الشريحة لازم يطابق البنك حرفيا** — الطفل ماسك المطبوعة وبيقارن.

### `glossary.md`
```markdown
| `G-137` | `decomposition` | التقسيم | نقسم المشروع الكبير لأجزاء صغيرة | `A1-S10` |
```
أى مصطلح ليه شريحة `term` **لازم** يكون فى المسرد.

## 3. قواعد الاستخدام

- **كل معرف فى `banks:` مستخدم فعلا** فى الخطة أو الشرائح أو الملاحظات. المعرف المذكور بلا استخدام = خطأ اتصلح `4` مرات فى `A1`.
- **كل معرف مستخدم مذكور** فى `banks:` وفى صف الجلسة فى `level.md`.
- **ما تكررش نفس النشاط** فى الافتتاح والفاصل بنفس الجلسة. حصل: `UP-06` فى الافتتاح و`UP-M-05` (نفس الفكرة) فى الفاصل بعدها بـ`20` دقيقة.
- **بطاقة المهارة تتوزع فى مكان واحد** متفق عليه فى التلات ملفات.
- **البطاقة المشتتة فى `Parsons`** بتبدأ من `S06` بس (تدرج مقصود).

## 4. لما تضيف مدخل جديد

1. خد الرقم التالى فى البنك.
2. اكتب المدخل بالصيغة الكاملة.
3. ضيفه لـ `banks:` فى الجلسة.
4. ضيفه لصف الجلسة فى `level.md`.
5. لو مصطلح — ضيفه للمسرد وللـ `glossary:` فى الـ `frontmatter`.
6. شغل `validate.mjs`.

## 5. أنشطة غير موصولة — إزاى تكتب واحد كويس

- **مدة `3` لـ `8` دقائق**، تجهيز بسيط أو صفر.
- **الطفل بيتحرك أو بيمسك حاجة** — مش بيتفرج.
- **بتنتهى بسؤال بيخلق الحاجة للمفهوم** — مش بتشرح المفهوم.
- الموجة الدلالية: **فكك** (`3` دقائق أسئلة من حياتهم) ← **استكشف** (`4` دقائق نشاط) ← **أعد التركيب** (`3` دقائق تسمية المفهوم).

مثال قوى من `A1-S06`: كتاب ورقى بيتقلب صفحة صفحة والحشرة بتتنقل، وينتهى بـ«الكمبيوتر يعرف منين إن الحشرة فين لما الصفحة تبقى `2`؟» — الطفل بيحتاج الإيفنت قبل ما يشوفه.
