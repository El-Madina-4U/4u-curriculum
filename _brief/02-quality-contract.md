مواصفات إلزامية — عقد الجودة

> **الملف ده هو المعيار.** أى مادة تخالف بند هنا = مرفوضة، حتى لو شكلها حلو.
> كل بند مكتوب بصيغة قابلة للفحص: تقدر تجاوب عليه بـ«اتحقق» أو «ما اتحققش».

## أ. بنية الجلسة والزمن

- [ ] مجموع مدد البلوكات **يساوى `90`** بالظبط.
- [ ] **مفيش بلوك مدته أكبر من `30`** دقيقة.
- [ ] البنية القياسية `7` بلوكات: `open:10` · `primm:20` · `break1:5` · `build:30` · `break2:5` · `fix:15` · `close:5`.
- [ ] الفواصل (`break1` و`break2`) **بعيدة عن الشاشة** — منصوص عليها فى الشرائح والملاحظات.
- [ ] بلوك `open` **مايبدأش بشرح على الشاشة** — نشاط غير موصول أو موجة دلالية أو عرض تحدى الجلسة السابقة.
- [ ] بلوك `close` موجود ومكتمل (عرض `30` ثانية لكل زوج · صفحة الدفتر · إعلان التحدى).
- [ ] النسخ الخاصة (`S01` · `Invent` `S12–S15` · `S16`) بتتبع جداولها فى `_shared/session-blocks.md` مش النسخة القياسية.

**قاعدة الضغط الزمنى:** لو الوقت ضاق، `fix` يتقلص أو يلغى. **`close` لا يلغى أبدا.** لازم تكون مكتوبة فى الملاحظات صراحة لكل جلسة فيها بناء تقيل.

## ب. `PRIMM` — بلوك القراءة

- [ ] التوزيع: `Predict 0–3` · `Run 3–5` · `Investigate 5–12` · `Modify 12–18` · جسر `18–20`.
- [ ] **التوقع مكتوب فى الدفتر قبل التشغيل** — مش «توقعوا بصوت عالى».
- [ ] الجلسة `A` بتعرض **النسخة المنتهية**. الجلسة `B` بتعرض **نسخة فيها خطأ مقصود واحد** من `bank-debug`.
- [ ] **صورة شريحة التوقع نضيفة** — بلا تحويط وبلا تسمية بتكشف الإجابة. النسخة المحوطة تتعرض فى `Investigate` بمعرف بلاحقة `b` (مثال: `A-SC-02` نضيفة · `A-SC-02b` محوطة).
- [ ] `Modify` = **تعديل واحد يقترحه الأطفال** وينفذه المدرس — مش عرض إضافى من المدرس.
- [ ] الكود المعروض على الشريحة **مطابق حرفيا** لملف المشروع (تحقق بـ `dump-sb3.mjs` أو بقراءة `index.html`).

## ج. دليل المدرس (`notes`) — أهم محور

- [ ] **كل مفهوم جديد فى `concepts_new` له قسم مستقل** بالشكل: `### جزئية: <اسم المفهوم>`.
- [ ] كل قسم فيه: **شرح أساسى** (اقتباس بصيغة كلام المدرس) + **أمثلة مرقمة** + **سؤال تكوينى** بإجابته الخاطئة المتوقعة والرد عليها.
- [ ] **عدد الأمثلة حسب التعقيد:**
  - مفهوم بسيط (`set size` · `next costume`) → **`2`**
  - متوسط (`event` · `x`/`y` · `layer`) → **`3`**
  - صعب أو محورى (`loop` · `rotation style` · الخلفية كمستوى) → **`4` أو أكتر**
- [ ] الأمثلة **من عوالم مختلفة**: مثال يومى · مثال من لعبة أو موبايل · مثال من الكود نفسه · ومثال مضاد لو المفهوم حدوده ملتبسة.
- [ ] كل مثال يبدأ بـ `- **مثال N** — ` أو `- **طريقة N** — ` (الـ `validate.mjs` بيعد بالشكل ده).
- [ ] **بلا رغى:** ممنوع تكرار جدول الخطوات اللى فى `sessions/Sxx.md`. الملاحظات تضيف: **إيه اللى المدرس يقوله حرفيا** · **لو اتعطلوا هنا** · **متى توقف الفوج كله**.
- [ ] جدول «الأخطاء المتوقعة» بتلات أعمدة: **الخطأ · السبب · الرد** — والرد جملة جاهزة للنطق.
- [ ] عمود «الشريحة» فى جداول البناء **بأرقام شرائح حقيقية** — ممنوع `#`.
- [ ] قسم «بعد الجلسة» فيه بنود تنفيذية بتغذى الجلسة اللى بعدها (مين اتعثر · مين سريع · رسالة ولى الأمر).
- [ ] لو المعمل ممكن يكون فيه `6` أجهزة بس بدل `12` — لازم يكون فيه بديل مكتوب لأى بلوك بيفترض جهاز لكل طفل.

## د. الشرائح

- [ ] **ملف `HTML` واحد مكتفى ذاتيا** — صفر `http` وصفر `CDN` (الـ `validate.mjs` بيرفض).
- [ ] الـ `CSS` والـ `JS` من `_templates/session.slides.html` عبر `node _tools/sync-slides.mjs` — **ممنوع تعدل `style` أو `script` داخل ملف جلسة**.
- [ ] `<body data-track="A">` أو `"B"` حسب المسار.
- [ ] **شريحة = فكرة واحدة.** شريحة الخطوة = تعليمة واحدة.
- [ ] **كل مصطلح إنجليزى فى نص عربى داخل `<code>`** — بدونها `BiDi` بيقلب الترتيب.
- [ ] الكود المتعدد الأسطر فى `<pre>` (القالب بيضبط `dir="ltr"`).
- [ ] كل بلوك ليه شريحة `block` فيها `<div class="num">البلوك N من M</div>` و`data-min` مطابقة للخطة — **شامل شرائح الفواصل**.
- [ ] خطوات البناء مرقمة بأرقام (`<span class="n">7</span>`) — **ممنوع إيموجى بدل رقم الخطوة**.
- [ ] آخر شريحة `sources` بالنص الثابت المذكور فى `_shared/slide-system.md` §4.
- [ ] كل صورة موجودة فعلا فى `assets/` ومسجلة فى `_shared/media-manifest.md`.
- [ ] الصورة بتشاور على **اللى الشريحة بتتكلم عنه** — مش على حاجة تانية.

## هـ. اللغة

- [ ] عامية مصرية بسيطة. جمل قصيرة.
- [ ] **صفر تشكيل** فى أى نص عربى (فحص: `perl -CSD -ne 'print if /[\x{064B}-\x{0652}\x{0670}]/'`).
- [ ] المصطلح إنجليزى + نطقه العربى أول ظهور: «الـ `sprite` — السبرايت».
- [ ] الأرقام إنجليزية.
- [ ] ممنوع ترجمة المصطلحات ترجمة فصيحة.
- [ ] الإيموجى باعتدال فى مسار `A` فقط.

## و. الاتساق بين الملفات التلاتة

لكل جلسة تلات ملفات: `sessions/Sxx.md` (الخطة) · `slides/Sxx.slides.html` (الشرائح) · `notes/Sxx.notes.md` (الملاحظات). لازم:

- [ ] نفس ترتيب البلوكات ونفس المدد فى التلاتة.
- [ ] نفس أسماء البلوكات والأرقام والقيم (لو الخطة بتقول `wait 6` مايبقاش فى الشرائح `wait 4`).
- [ ] نفس سؤال الدفتر ونفس التحدى الاختيارى — حرفيا فى الأربع مواضع (`frontmatter` · الخطة · الشرائح · الملاحظات).
- [ ] كل معرف بنك مذكور فى `banks:` **مستخدم فعلا**، وكل معرف مستخدم **مذكور**.
- [ ] صف الجلسة فى `<level>/level.md` مطابق لـ `frontmatter`.
- [ ] `media:` فى `frontmatter` = الصور المستخدمة فعلا فى الشرائح، لا أكتر ولا أقل.

## ز. المشاريع وملفات الطفل

- [ ] ملف `PRIMM` (`P*-final` أو `debug/DB-*`) بيفتح على **حالة بداية نظيفة** — مش حالة ما بعد التشغيل.
- [ ] ملف `after-A` = **حالة نهاية الجلسة `A` بالظبط** — لا سبرايت زيادة، لا خلفية زيادة، لا سكربت من جلسة جاية.
- [ ] ملف `debug` فيه **خطأ واحد بس**، وباقى المشروع مطابق لحالة الطفل فى اللحظة دى.
- [ ] كل الملفات المشتقة بتتولد بـ `node _tools/make-checkpoints.mjs` — **ممنوع تعديل يدوى**.
- [ ] الملف بيفتح فى `Scratch` من غير أخطاء (اختبار تحميل فعلى).
