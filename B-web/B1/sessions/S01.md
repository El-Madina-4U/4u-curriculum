# `B1-S01` — كل موقع فى الدنيا مكتوب كده

> **النوع:** جلسة افتتاح — نسخة `S01` من القالب
> **الناتج بنهاية الجلسة:** كل طالب كتب أول صفحة `HTML` بإيده، لونها بـ `CSS`، شافها فى المتصفح، وفتح `F12` على موقع حقيقى.

## بلوك التشخيص — `UP-11` + ورقة الربط

`10` دقايق `UP-11`: صفحة موقع بسيط مطبوعة ملونة — «حوط كل عنوان بالأحمر، كل فقرة بالأزرق، كل صورة بالأخضر.»

**الصفحة المطبوعة — المحتوى المطلوب** (أصل واحد يتصور `12` نسخة ملونة): عنوان كبير واحد · عنوان فرعى أصغر تحته · `3` فقرات · صورتين · رابط واحد بلون مختلف وتحته خط.

ثم `5` دقايق **ورقة الربط**: عمودين. عمود فيه `5` تاجات — `h1` · `h2` · `p` · `img` · `a` — وعمود فيه نفس أجزاء الصفحة بالأسماء العربية (العنوان الكبير · العنوان الفرعى · فقرة · صورة · الرابط) بترتيب مخلوط. الطالب يوصل بخط.

**قائمة المراقبة** — ورقة واحدة عند المدرس: عمود الأسماء و`4` خانات علامة لكل اسم.

| # | المؤشر |
| --- | --- |
| `1` | حوط الأنواع التلاتة صح |
| `2` | وصل `h1` و`p` و`img` صح على الأقل |
| `3` | قرا التاج بصوت من غير مساعدة |
| `4` | اشتغل مستقلا — ما سألش الجار |

**الغرض: الأزواج.** الدرجة = عدد الخانات (`0–4`) وتتحسب فى فاصل `break2`.

## بلوك المفاجأة — أول صفحة ليك

فولدر `first-page/` على كل جهاز — نسخة من `B-web/B1/checkpoints/first-page/`:

| الملف | فيه إيه |
| --- | --- |
| `index.html` | `<head>` جاهز وفيه `<link href="style.css">`. و`body` فيه تلات كومنتات: «اكتب هنا: عنوان `h1`» · «فقرة `p` عن حاجة بتحبها» · «صورة» |
| `style.css` | أربع قواعد جاهزة: `body` (الخط والخلفية) · `h1` (`color: #7c3aed` و`font-size: 48px`) · `p` (`font-size: 20px`) · `img` (`width: 300px`) |
| `game-boy.jpg` | صورة جاهزة للاستخدام |
| `fish.jpg` | صورة جاهزة للاستخدام |

> «المهمة: صفحة عنك — بس **بدون اسمك الكامل**. اسم مستعار أو اسمك الأول. عنوان `h1`. فقرة `p` عن حاجة بتحبها. صورة: `<img src="game-boy.jpg">` أو `<img src="fish.jpg">` — الاسم بالظبط زى اللى فى الفولدر. وبعدين فى `style.css`: غير اللون. غير الرقم. **غير أى حاجة وشوف.** حفظ و`F5` كل مرة.»

| الدقيقة | ماذا يحدث |
| --- | --- |
| `0–3` | التعليمات + بطاقة `SK-B-01` |
| `3–15` | كل طالب لوحده. المدرس يلف: «غيرت إيه؟ حصل إيه؟» |
| `15–17` | «الكل: `Ctrl+S`. اتأكد الملف فى فولدرك.» |
| `17–25` | يكملوا. المدرس يعلم `3` صفحات للعرض |

**تلميحات على الشريحة:** `color` · `font-size: 60px` · `background: yellow` · `text-align: center` · جرب اسم لون بالإنجليزى.

## الأزواج والدفتر

**التزويج يتحسب فى فاصل `break2`:** رتب الـ `12` اسم تنازليا بعدد المؤشرات (`0–4`) وزوج المتجاورين فى الترتيب — `4` مع `4` و`1` مع `1`. **مش** الأعلى مع الأدنى (`pedagogy.md` §`7`). عدد فردى؟ ثلاثى واحد بأدوار سائق · ملاح · مختبر وتبديل كل `10` دقايق (`session-blocks.md` قاعدة `6`).

الإعلان بالاسم + شرح السائق والملاح. الدفتر: «أنا اسمى / موقع نفسى أعمله: ___».
