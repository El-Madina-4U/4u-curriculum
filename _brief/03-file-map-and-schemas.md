## 2. مخطط `frontmatter` لخطة الجلسة

كل ملف `sessions/Sxx.md` بيبدأ بـ `YAML` بين `---`:

```yaml
id: A1-S04                  # <المستوى>-S<الرقم>  إلزامى ومطابق للمسار
level: A1                   # A1|A2|A3|B1|B2
seq: 4                      # رقم الجلسة 1..16
type: standard              # standard|opening|invent|showcase
duration_min: 90            # دايما 90
project: catch-the-bus      # slug المشروع من level.md أو none
project_half: A             # A|B|none  (الجلسة الأولى أو التانية من المشروع)
stage: explore              # intro|explore|design|invent
concepts: [...]             # كل المفاهيم المستخدمة (جديدة وقديمة)
concepts_new: [...]         # الجديدة بس — كل واحد لازم له جزئية فى notes
glossary: [G-109, G-125]    # معرفات المسرد المستخدمة
prereq: [A1-S03]            # الجلسة/الجلسات السابقة المطلوبة، أو [none]
source: https://projects.raspberrypi.org/en/projects/<slug>
banks: [UP-03, PS-A-04, ...]  # كل معرف بنك مستخدم — لا أكتر ولا أقل
skill_block: none           # none|digital-safety|ai-tools-demo|github
blocks: [open:10, primm:20, break1:5, build:30, break2:5, fix:15, close:5]
slides: slides/S04.slides.html
notes: notes/S04.notes.md
checkpoint: checkpoints/P2-after-A.sb3   # أو none
media: [A-PR-02, A-BL-01]   # معرفات الصور المستخدمة فى الشرائح
journal_question: "..."     # سؤال الدفتر — نص واحد يتكرر حرفيا فى 4 مواضع
optional_challenge: "..."   # التحدى الاختيارى — نفس الكلام
---
```

**قواعد:**
- مجموع `blocks` لازم `= 90`، وكل قيمة `<= 30`.
- `concepts_new` هو مصدر الحقيقة لعدد أقسام `### جزئية` فى الملاحظات.
- `media` لازم يطابق الصور المستخدمة فعلا فى ملف الشرائح.

## 3. هيكل خطة الجلسة (بعد الـ `frontmatter`)

```markdown
# `A1-S04` — <عنوان الجلسة>

> **المشروع:** ... — الجلسة `A` من `2`
> **المرحلة:** `Explore`
> **الناتج بنهاية الجلسة:** جملة واحدة محددة وقابلة للملاحظة.

## الهدف
## المفاهيم            جدول: المفهوم | جديد؟ | المسرد
## البلوكات            جدول: # | البلوك | المدة | المحتوى | المعرف
## بلوك PRIMM — تفصيل  جدول: المرحلة | ماذا يعرض | السؤال
## بلوك البناء — الخطوات  جدول: # | الخطوة | الشريحة | البطاقة
## خلص بدرى / اتعثر
## الختام
## التجهيز
```

## 4. هيكل ملاحظات المدرس

```markdown
# `A1-S04` — ملاحظات المدرس

> **اقرأ ده كله قبل الجلسة.** جملة عن أهمية الجلسة.
> الأمثلة: أكتر من واحد لكل مفهوم — **اختار اللى يناسب أطفالك**.

## قبل الجلسة — `15` دقيقة        قائمة [ ] تنفيذية، مش تكرار للخطة
## البلوك `1` — افتتاح — `10` دقايق
   نص حرفى بصيغة اقتباس + توقيت بالدقيقة
## البلوك `2` — `PRIMM` — `20` دقيقة
   ### جزئية: <مفهوم>
     **الشرح الأساسى:** اقتباس
     - **مثال 1** — يومى: ...
     - **مثال 2** — لعبة: ...
     - **مثال 3** — من الكود: ...
     **السؤال التكوينى:** ... — الإجابة الغلط المتوقعة ... **الرد:** ...
   ### خطوات `PRIMM` بالدقيقة     جدول: الدقيقة | الشريحة | افعل | قول
## البلوك `3` — فاصل              سطر تنفيذى بمحتوى النشاط مش بمعرفه بس
## البلوك `4` — بناء — `30` دقيقة
   جدول: الخطوة | الشريحة | لو اتعطلوا هنا | متى توقف الفوج كله
## البلوك `5` — فاصل
## البلوك `6` — تثبيت أو مهارة    جدول بالدقيقة
## البلوك `7` — ختام              جدول بالدقيقة
## الأخطاء المتوقعة               جدول: الخطأ | السبب | الرد
## بعد الجلسة                     قائمة [ ] بتغذى الجلسة الجاية
```

## 5. هيكل ملف المستوى `level.md`

```markdown
# المستوى A1 — Scratch (10–12)
## الهدف
## المشاريع            جدول: P | المرحلة | الاسم | الجلسات | المفاهيم | المخرج
## خريطة الجلسات       جدول: الجلسة | النوع | المشروع | المفاهيم | بلوك المهارة | البنوك
## ملفات checkpoints   جدول: الملف | الحالة | يستخدم فى
## بطاقات المهارات     جدول: الجلسة | البطاقات
## التكييف الثقافى
```

**صف الجلسة فى «خريطة الجلسات» لازم يطابق `banks:` فى الـ `frontmatter` حرفيا.**

## 6. `manifest.yml`

المصدر الوحيد لترتيب المستويات والجلسات. `validate.mjs` بيقراه ويتأكد إن كل جلسة مذكورة ليها ملفات.

```yaml
meta: { session_min: 90, sessions_per_level: 16, cohort_size: 12, late_entry_cutoff: S05 }
tracks:
  A: { name: Scratch, ages: [10,12], accounts: none, levels: [A1, A2, A3] }
  B: { name: Web, ages: [13,16], levels: [B1, B2] }
levels:
  - id: A1
    status: built            # built | skeleton
    projects: [ {id, stage, slug, name, sessions}, ... ]
```

لما تخلص مستوى، غير `status` من `skeleton` لـ `built`.

## 7. `media-manifest.md`

كل صورة ليها صف:

```
| المعرف | الملف | الحالة | المصدر | الوظيفة التفسيرية | الجلسات |
| `A-BL-05` | `A-BL-05.png` | `done` | لقطة `Scratch` + تحويط | `repeat` و`forever` | `S04` `S07` |
```

**ما تحدثوش بإيدك** — شغل:
```
node _tools/sync-manifest.mjs
```
بيملى عمود الجلسات من الاستخدام الفعلى فى الشرائح، ويظبط الحالة، ويضيف صفوف للصور الجديدة.
