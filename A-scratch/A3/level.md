## المخرج النهائى

محاكاة `2.5D` بمنظور الشخص الأول (`FPV`) — مشهد مسطح بيبان مجسم — **تلبى بريفا مكتوبا**:

- أحجام سبرايتات مختلفة بتمثل بعد الحاجة عن العين
- كلونات بتولد النسخ بدل ما تترسم واحدة واحدة
- `My Blocks` للتنظيم أو للمدخلات

**موضوع المحاكاة حر تماما، والبنية التقنية محددة.** ده فرق جوهرى عن `A1` و`A2`: هنا لأول مرة الطفل بيتقيم على **شروط مكتوبة** مش على «عمل حاجة حلوة».

> **نص البريف الرسمى حرفيا** (`welcome-to-my-world` — `step_1`):
> *Your simulation **should**: use different sized sprites to represent the distance of the object from the viewer · use clones to generate copies of sprites · use `My Blocks` to keep your code organised and/or allow the use of inputs.*
> *Your simulation **could**: have an educational theme · use sounds or music to make the simulation appear more realistic.*

وهو آخر مستوى فى مسار `A` قبل الانتقال لمسار الويب.

## المتطلب السابق

إتمام `A2` — أو اجتياز تشخيص: `broadcast` · `if` · المتغير · `touching` · `and`/`or`/`not`.

## التسلسل من `A2`

`A2` أعطى الأدوات مفردة: رسالة · شرط · متغير · `and` و`or` و`not` كل واحد لوحده.

`A3` **مابيقدمش أدوات جديدة كتير — بيركب اللى فات**. التلاتة اللى بيضيفهم:

| الجديد | يعنى إيه | المشروع |
| --- | --- | --- |
| **التنظيم** | البلوك اللى إنت مؤلفه — `My Blocks` | `P1` بلا مدخلات · `P3` بمدخلات |
| **المنطق المركب** | `(touching port) and (not (touching color))` — تعبير واحد من تلات عمليات | `P2` |
| **التوليد** | الكلون: كيان حى ليه كوده وقيمه وبيمسح نفسه | `P3` و`P4` |

> **قراءة مهمة:** نص «الجديد» فى `A3` مش جديد — هو **تعميق** لـ `A2`. `and` و`or` و`not` و`nested if` اتقدموا فى `A2`. جلسات `S04`–`S05` هنا **تركيب ومراجعة، مش تقديم أول**. المدرس لازم يعرف الفرق ده وإلا هيضيع `20` دقيقة يشرح حاجة الطفل عارفها.

### تصحيح جوهرى فى ترتيب المفاهيم

النسخة القديمة كانت بتنسب `clones` لـ `P1` و`my blocks` لـ `P2` و`boolean` لـ `P3`. **الترتيب الصحيح مقلوب:**

- **`P1` = `my blocks`** (بلا مدخلات). فيه بلوك `create clone of` **واحد بس** — لغرض السكرول، مش لتعليم الكلونات (اتأكد بالعد فى الملف).
- **`P2` = `boolean`** — هو مشروع المنطق الحقيقى (`and`×`2` · `or`×`1` · `not`×`2` · `repeat until`×`5` فى الملف النهائى).
- **`P3` = `clones`** + `my blocks` بمدخلات (`21` مرجع بارامتر فى الملف النهائى).

**الترتيب المصحح: `my blocks` ← `boolean` ← `clones`.**

## عيوب فى المادة الأصلية — **اتأكدت بالفحص، ولازم تتصلح عندنا**

هنا أخطر قسم فى الملف. تلات عيوب لو اتنقلت زى ما هى، الجلسة بتقع فى المعمل.

### `1` — ملف بداية `Mandala` **بيحرق الدرس كله**

`P3-mandala-starter.sb3` (`540476254`) المفروض يكون نقطة البداية للخطوة `2`، واللى بيطلب من الطفل يعمل `My Block` جديد ويضيف له مدخل. **لكن الملف بيحتوى بالفعل على البلوك كامل بأربع مدخلات وجسمه كله:**

```
define pattern: (repeat) (size) (move) (turn)
  repeat (repeat)
    change size by (size)
    move (move) steps
    create clone of (myself)
    turn cw (turn) degrees
```

ومعاه الاستدعاء جاهز. يعنى الطفل هيفتح الملف فيلاقى شغل الخطوتين `2` و`3` معمول.

**الحل:** يتولد `P3-starter-blank.sb3` من الأصل بحذف تعريف `pattern:` والاستدعاء، ويفضل الكوستيومات والتهيئة. الأصل يتحفظ فى `checkpoints/_src/` كما نزل.

### `2` — `Mandala` بيستخدم `answer` قبل ما يقدم `ask and wait`

الخطوة `5` فيها `switch costume to ((answer) + (1))` والخطوة اللى بتقدم `ask and wait` هى `7`. لو الطفل مشى بالترتيب حرفيا، `answer` هيبقى فاضى والكوستيوم مش هيتغير.

**الحل:** فى نسختنا `ask and wait` تتقدم لـ `S07` **قبل** بلوك التلوين، أو يستبدل `answer` برقم ثابت وقت التجربة الأولى.

### `3` — أمثلة `P4` فيها `mod` واللى الخطوة مابتشرحوش

فحص الملفات: `P4-swarms-main.sb3` و`P4-swarms-fish-feeder.sb3` فيهم `operator_mod`×`2` لكل واحد. **ونص خطوة `2` نفسه مافيهوش `mod` خالص** — بيستخدم `set x to` و`x position` (اتأكد بقراءة نص الخطوة).

**الحل:** `mod` يفضل `G-314` أول ظهور فى `S13` كما هو. ويتكتب فى ملاحظات المدرس تحذير: **لو فتحت `P4-swarms-main` بـ `See inside` قدام الأطفال هتقابل بلوك `mod` مش مشروح — عدى عليه ولا تفتح الموضوع.**

## الجسر لمسار `B` — خاص بـ `A3`

`A3` هو آخر مستوى قبل الويب، والمسار ده — بغض النظر عن نية واضعيه — بيعلم أربع عادات ذهنية هى بالظبط اللى بتفرق بين طفل بيلعب بالبلوكات وطفل مستعد يكتب كود نصى.

**`1` — `My Blocks` هى الدالة.** فى `P1` الطفل بيلم سلسلة أوامر طويلة تحت اسم واحد وينادى الاسم — ده `function` بلا `parameters`. وفى `P3` بيحط خانات فاضية ويملاها وقت الاستدعاء فتطلع نتيجة مختلفة كل مرة — ده `function` بـ `arguments`. اللى استدعى `pattern: repeat (3) size (10) move (5) turn (60)` تلات مرات بقيم مختلفة وشاف تلات أشكال، **فهم الدالة عمليا**. هو بس مشافش شكلها المكتوب.

**`2` — `boolean` كنوع بيانات.** فى `P2` بيركب `(touching port) and (not (touching color))`، وبيخزن `true`/`false` فى متغير `at chair` ويقراه بعدين. المسافة بين ده وبين `if (isOpen && !isLocked)` هى المسافة بين شكلين للحاجة نفسها.

**`3` — الكيان اللى له حالة.** الكلون فى `P3` و`P4` بيشغل `when I start as a clone` بنفسه وبيحمل قيمه وبيمسح نفسه. اللى عمل `repeat (20) → create clone of myself` وشاف عشرين كائنا كل واحد بيتصرف لوحده، لمس فكرة «نسخ من قالب» — نفس الفكرة فى `DOM` لما يولد عناصر متكررة.

**`4` — البناء من بريف وقائمة فحص.** `P6` مابيديش خطوات، بيدى **شروطا** (`should` و`could`) وبنك وصفات. وده بالظبط شغل `B1` من `S08` فصاعدا.

### ما لا يمهد له المسار — **يتقال صراحة**

- **مافيش `list`** ← فمافيش تمهيد لـ `array` خالص (اتأكد بفحص الـ `18` ملف)
- **مافيش `return value`** — بلوكات `Scratch` المخصصة مابترجعش قيمة
- مافيش تعامل مع النصوص أبعد من `join`
- مافيش نص مكتوب على الإطلاق

> **فجوة `return` تستحق بلوك مهارة مستقلا:** «البلوك بينفذ حاجة، بس مابيرجعش نتيجة — فى `JavaScript` بيقدر يعمل الاتنين.»

### بلوكا `S14` و`S15` — جدول المقارنة

محوره **الدالة قبل أى حاجة تانية**:

```
define pattern: repeat (n)   →   function pattern(n) { ... }
pattern: repeat (3)          →   pattern(3);
(a) and (b)                  →   a && b
not (a)                      →   !a
repeat until <a>             →   while (!a) { ... }
create clone of myself       →   نسخة جديدة من قالب
```

**`S16`** التأمل: «اللى عملته فى `Scratch` — لو عايز تعمله موقع؟» — تمهيد `B1`.
الطفل اللى بيكمل `A3` وعمره `12` يدخل `B1`، و`GitHub` تحت منظمة الأكاديمية لحد `13`.
