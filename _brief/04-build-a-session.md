إجراء بناء جلسة من الصفر

> امشى بالترتيب. ما تقفزش خطوة.
> الزمن التقديرى لجلسة كاملة بالجودة المطلوبة: من `3` لـ `5` ساعات شغل موديل.

---

## المرحلة `0` — قبل أى جلسة فى المستوى (مرة واحدة للمستوى كله)

1. **اختار المشاريع الست** من مسارات `Raspberry Pi` حسب مواصفة المستوى فى `12-remaining-work.md`.
   البنية إلزامية: `3` مشاريع `Explore` + `2` `Design` + `1` `Invent`.
2. **حمل خطوات كل مشروع** من المصدر عشان تكتب جلسات دقيقة:
   ```
   https://raw.githubusercontent.com/raspberrypilearning/<slug>/master/en/step_1.md
   ```
   (غير الرقم للخطوات التانية.)
3. **حمل ملفات المشاريع:**
   - `Scratch`: `node _tools/fetch-scratch.mjs <projectId> <out.sb3>`
   - ويب: `node _tools/fetch-rpi-web.mjs <identifier> <outDir>`
4. **املا `<level>/level.md`** بالكامل: المشاريع، خريطة الـ `16` جلسة، المفاهيم لكل جلسة، ملفات `checkpoints` المطلوبة، بطاقات المهارات.
5. **حدث `manifest.yml`** بمشاريع المستوى.
6. **راجع سلم المفاهيم:** كل مفهوم بيتقدم مرة واحدة، والجلسة اللى بعده بتستخدمه. مفيش مفهوم بيظهر قبل متطلبه.

---

## المرحلة `1` — تجهيز مواد الجلسة الواحدة

7. **حدد بنية الجلسة** من `_shared/session-blocks.md` (قياسية ولا نسخة خاصة).
8. **حدد المفاهيم الجديدة** — دى هتحدد أقسام `### جزئية` فى الملاحظات.
9. **افتح ملف المشروع واقراه فعليا:**
   ```
   node _tools/dump-sb3.mjs <ملف>
   ```
   اكتب لنفسك: أسماء السبرايتات · أسماء الكوستيومات والخلفيات · كل رقم فى كل بلوك.
   **كل كود هتكتبه بعد كده لازم يطابق الخرج ده.**

---

## المرحلة `2` — كتابة خطة الجلسة

10. انسخ `_templates/session.md`.
11. املا الـ `frontmatter` كامل (المخطط فى `03-file-map-and-schemas.md`).
12. اكتب **الناتج بنهاية الجلسة** جملة واحدة قابلة للملاحظة: «أتوبيس فى مكانه، وقطة بتمشى له بلوب لما نضغط العلم».
13. جدول البلوكات — المجموع `90` بالظبط.
14. تفصيل `PRIMM` — المراحل الأربعة بأسئلتها.
15. جدول خطوات البناء — كل خطوة سطر واحد، وعمود الشريحة **يتملى بعدين** لما الشرائح تتكتب.
16. «خلص بدرى / اتعثر» + الختام + التجهيز.

---

## المرحلة `3` — كتابة الشرائح

17. انسخ ملف شرائح موجود من `A1` كأساس (مش القالب — الملف الكامل)، وامسح الـ `<section>` بس.
18. اكتب الشرائح بالترتيب. الحد الأدنى لكل جلسة قياسية:
    - `title`
    - `block` لكل بلوك من السبعة (**شامل الفواصل**) مع `data-min` و`.num`
    - محتوى الافتتاح
    - `predict` بصورة **نضيفة** + `ask` بعد التشغيل + صورة **محوطة** فى `Investigate`
    - `term` لكل مفهوم جديد
    - `step` لكل خطوة بناء — تعليمة واحدة + لقطة
    - `card` لكل بطاقة مهارة بتتوزع
    - `challenge` لـ«خلص بدرى» ولـ«التحدى الاختيارى»
    - شريحة سؤال الدفتر
    - `sources` بالنص الثابت
19. **راجع كل كود إنجليزى:** جوه `<code>` أو `<pre>`؟
20. حدث عمود «الشريحة» فى الخطة بأرقام الشرائح الحقيقية.

---

## المرحلة `4` — كتابة ملاحظات المدرس

21. انسخ `_templates/session.notes.md`.
22. **«قبل الجلسة»** — بنود تنفيذية بس. لكل ملف مشروع اكتب **إزاى تتأكد إنه سليم** («اضغط العلم: القطة تنط مرة وتقف؟»).
23. لكل مفهوم جديد: قسم `### جزئية` بالشرح الأساسى + الأمثلة (العدد حسب التعقيد) + سؤال تكوينى.
24. جدول `PRIMM` بالدقيقة بأعمدة: الدقيقة · **الشريحة** · افعل · قول.
25. جدول البناء بأعمدة: الخطوة · الشريحة · **لو اتعطلوا هنا** · **متى توقف الفوج كله**.
26. الفواصل: اكتب **محتوى النشاط** مش معرفه بس.
27. جدول «الأخطاء المتوقعة» — `6` صفوف على الأقل، كل واحد بالسبب والرد المنطوق.
28. «بعد الجلسة» — بنود بتغذى الجلسة اللى بعدها.
29. **امسح أى تكرار للخطة.**

---

## المرحلة `5` — ملفات المشروع

30. أضف قواعد التوليد فى `_tools/make-checkpoints.mjs`:
    - تطبيع الملف النهائى (حالة بداية نظيفة).
    - `P<n>-after-A` = ناتج الجلسة `A` بالظبط.
    - `debug/DB-<track>-<nn>` = حالة الطفل + خطأ واحد.
31. شغل التوليد وافحص:
    ```
    node _tools/make-checkpoints.mjs
    node _tools/dump-sb3.mjs <كل ملف اتولد>
    ```
32. حمل كل ملف فى `Scratch` فعليا وتأكد إنه بيفتح وبيشتغل زى المكتوب.

---

## المرحلة `6` — الصور

33. أضف تعريف كل لقطة فى `_tools/capture.mjs` (شوف `08-projects-and-assets.md`).
34. شغل:
    ```
    node _tools/capture.mjs <معرفات>
    node _tools/sync-manifest.mjs
    ```
35. افتح كل لقطة وشوفها. اسأل: **البلوك المحوط مقروء من آخر الفصل؟** **الصورة بتشاور على اللى الشريحة بتتكلم عنه؟**

---

## المرحلة `7` — التحقق والمراجعة

36. ```
    node _tools/validate.mjs
    ```
    لازم «كل الفحوصات نجحت».
37. صور الشرائح وافحصها بصريا:
    ```
    node _tools/render-deck.mjs <deck> _review/.render/<id>
    ```
    افتح **كل** صورة. دور على: تراكب · نص مقطوع · لخبطة اتجاه · صورة فوق نص · شريحة مزدحمة.
38. امشى على `02-quality-contract.md` بند بند.
39. امشى على `10-failure-catalogue.md` نمط نمط.
40. شغل مراجعة مستقلة (`11-review-protocol.md`) — مراجع تانى ما شافش الشغل.
41. صلح نقاط التقرير، وأعد `validate.mjs`.
42. **امسح التشكيل:**
    ```
    LC_ALL=C.UTF-8 perl -CSD -i -pe 's/[\x{064B}-\x{0652}\x{0670}]//g' <ملفات الجلسة>
    ```

## قائمة تسليم الجلسة

- [ ] `sessions/Sxx.md` · `slides/Sxx.slides.html` · `notes/Sxx.notes.md` موجودين ومتسقين
- [ ] مجموع الزمن `90` ولا بلوك `> 30`
- [ ] كل مفهوم جديد له جزئية بالعدد المطلوب من الأمثلة
- [ ] كل كود مطابق لملف المشروع (متحقق بـ `dump-sb3`)
- [ ] كل صورة موجودة ومسجلة وبتشاور على الصح
- [ ] ملفات `checkpoints` اتولدت واتفتحت فى `Scratch`
- [ ] `level.md` و`manifest.yml` محدثين
- [ ] `validate.mjs` عدى
- [ ] الشرائح اتفحصت بصريا صورة صورة
- [ ] صفر تشكيل
