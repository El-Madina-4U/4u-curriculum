# `B1-S02` — بنية الصفحة 🏗️

> **المشروع:** `Anime expressions` — الجلسة `A` من `2`
> **المرحلة:** `Explore`
> **الناتج بنهاية الجلسة:** صفحة بعنوان رئيسى، ومقدمة، وقسم أول فيه صورة وشرح — بـ `HTML` خام بدون تنسيق.

---

## الهدف

بنهاية الجلسة الطالب يعرف إن الصفحة تلات أجزاء، يقسم المحتوى لأقسام، يكتب عناوين وفقرات وصور بأتريبيوتاتها، ويفهم الكومنت.

## المفاهيم

| المفهوم | جديد؟ | المسرد |
| --- | --- | --- |
| `header` · `main` · `footer` | **جديد** | `G-237` |
| `section` | **جديد** | `G-236` |
| `h1` · `h2` · `p` | **جديد** رسميا | `G-208` `G-209` |
| الكومنت `<!-- -->` | **جديد** | `G-238` |
| `img` · `src` · `alt` — الأتريبيوت | **جديد** | `G-210` `G-207` `G-239` |

## بلوك `PRIMM` — تفصيل

**الملف:** `P1-final/index.html` — محليا فى `VS Code` على جهاز البروجيكتور. **بدون إنترنت.**

| المرحلة | ماذا يعرض | السؤال |
| --- | --- | --- |
| `Predict` | الصفحة النهائية **مخفية** — الكود بس | «من الكود: الصفحة فيها إيه؟ عدوا: عناوين، فقرات، صور.» يكتبوا |
| `Run` | الصفحة | «كام عنوان؟ كام صورة؟ اللى توقعتوه؟» |
| `Investigate` | `F12` ← الهيكل: `header` ← `main` ← `section` × `4` ← `footer` | «التلات أجزاء. ليه `main` فيه `section` كتير؟» · **امسح سطر `<link ... style.css>`** ← `F5` — الصفحة بقت خام | «نفس الكلام. الشكل راح. ده `CSS`.» رجعه |
| `Modify` | تعديلين — `6` دقايق | `1` «غير كلمة فى `h1`.» ← حفظ ← `F5`. `2` «شيلوا `<section>` كاملة — إيه اللى راح؟» ← `Ctrl+Z` ترجعها |

**الربط:** «النهاردة الهيكل بس — `HTML` خام. الجلسة الجاية الشكل.»
