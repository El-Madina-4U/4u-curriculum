# نظام الشرائح

> كل عرض ملف `HTML` واحد مكتف ذاتيا. الـ `CSS` والـ `JS` من `_templates/session.slides.html`.
> تعديل النظام = تعديل القالب ثم تشغيل `node _tools/sync-slides.mjs` — بيحدث كل العروض.

---

## 1. القواعد الحاكمة

| القاعدة | السبب |
| --- | --- |
| **ملف واحد، لا مراجع خارجية** | يشتغل والنت واقع. `validate.mjs` بيرفض أى `http` أو `cdn` |
| **خطوط النظام فقط** | `Segoe UI` · `Tahoma` · `Arial` — موجودة على أى ويندوز |
| **خلفية فاتحة** | بروجيكتور فى فصل منور. الداكن مايتشافش |
| **أصغر خط `24px`** للنص العادى · و`28px` فما فوق للمحتوى الأساسى | آخر ترابيزة لازم تقرا. التفصيل تحت |
| **شريحة = فكرة واحدة** | لو محتاجة سكرول، تتقسم |
| **الكود `LTR` معزول** | `<pre dir="ltr">` دائما |
| **الصور لقطات حقيقية** | من `assets/` — الوظيفة التفسيرية مكتوبة فى `notes` |

### أرضية حجم الخط — بالتفصيل

الأرضية **نسبة من ارتفاع الشريحة**، مش رقم بكسل مطلق. حجم الخط الأساسى `min(3.11vh, 1.75vw)` — يعنى `28px` على الدقة المرجعية `1600×900`، وبيتدرج مع أى دقة تانية. البروجيكتور بيكبر الشريحة، فالنسبة هى اللى بتحدد القراءة مش البكسل.

| النوع | الأرضية | أمثلة |
| --- | --- | --- |
| **المحتوى الأساسى** | `28px` على `1600×900` | العناوين · الفقرات · بنود القوائم · الكود فى `<pre>` |
| **النص الثانوى** | `24px` | `.kicker` · `.muted` · `.tag` · معرف بطاقة المهارة · شريحة المصادر |
| **ممنوع** | أقل من `24px` | أى نص مهما كان دوره |

**الفحص الآلى** بيقيس الأرضية الدنيا (`24px`) على الدقة المرجعية بس، وبيفحص تجاوز الإطار على كل الدقات:

```
node _tools/check-decks.mjs
node _tools/check-decks.mjs --w 1280 --h 720
```

## 3. أنواع الشرائح

كل شريحة `<section class="slide TYPE" data-min="N">`. الـ `data-min` = دقائق البلوك، بيظهر مؤقت للمدرس.

| النوع | الكلاس | المحتوى | مثال الاستخدام |
| --- | --- | --- | --- |
| **عنوان** | `title` | اسم الجلسة + المستوى + رقمها | أول شريحة |
| **بلوك** | `block` | اسم البلوك + مدته + إيه اللى هيحصل | بداية كل بلوك |
| **مصطلح** | `term` | المصطلح الإنجليزى كبير + النطق + التعريف + لقطة | أول ظهور لمصطلح |
| **توقع** | `predict` | كود/لقطة + «هيحصل إيه؟» + مكان للتوقعات | بلوك `PRIMM` |
| **خطوة** | `step` | رقم الخطوة + تعليمة واحدة + لقطة شاشة | بلوك البناء — الأكتر عددا |
| **كود** | `code` | كود `LTR` كبير + شرح سطر | مسار `B` أساسا |
| **سؤال** | `ask` | سؤال واحد كبير للنقاش | أى وقت |
| **فاصل** | `break` | اسم نشاط الحركة + مؤقت كبير | بلوكات الفاصل |
| **بطاقة** | `card` | بطاقة مهارة كاملة | عند توزيع بطاقة |
| **تحدى** | `challenge` | التحدى الاختيارى | قبل الأخيرة |
| **مصادر** | `sources` | **ثابتة** — آخر شريحة دائما | نهاية كل عرض |

## 5. التحكم

| الفعل | الطريقة |
| --- | --- |
| التالى | `→` أو `Space` أو `PgDn` أو ضغطة على النص الأيسر من الشاشة |
| السابق | `←` أو `PgUp` أو ضغطة على النص الأيمن |
| شريحة رقم | اكتب الرقم ثم `Enter` |
| المؤقت | `T` يبدأ ويوقف مؤقت الشريحة الحالية |
| ملء الشاشة | `F` |
| الطباعة | `Ctrl+P` — كل شريحة صفحة |
| القائمة | `Esc` — عرض مصغر لكل الشرائح |

**فى `RTL`:** «التالى» على الشمال. الأسهم متعاكسة عمدا عشان تناسب اتجاه القراءة.

## 6. الصور

- المسار نسبى: `../assets/S03-01.png`.
- الاسم: `Sxx-nn.png` — رقم الجلسة ثم الترتيب.

- كل صورة فى `media-manifest.md` بمعرفها ووظيفتها.

## 7. الكتابة على الشريحة

- عامية مصرية بسيطة. جملة قصيرة.
- المصطلح إنجليزى `<code>` + النطق العربى بجانبه أول مرة.
- الأرقام إنجليزية `1 2 3` — أوضح على البروجيكتور.
- **لا** نقط كتير. شريحة الخطوة = تعليمة واحدة.
- الإيموجى مسموح باعتدال فى مسار `A` للأطفال الأصغر — ✅ ❌ 👀 🎉.
