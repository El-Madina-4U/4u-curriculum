# سلامة الأطفال — القواعد والنماذج

> مش اختيارى. أى جلسة بتخالف بند هنا تتوقف.

## 1. القواعد الثابتة

### 1.1 الحسابات على الإنترنت

| المنصة | الحد الأدنى | مسار `A` | مسار `B` |
| --- | --- | --- | --- |
| `Scratch` | إيميل ولى أمر تحت `16` | **لا حسابات** — ملفات محلية | لا يستخدم |
| `GitHub` | `13` | **ممنوع** | ولى الأمر ينشئه فى البيت |
| `ChatGPT` | `13` بموافقة | **ممنوع** | اختيارى بموافقة مكتوبة |
| `Claude.ai` | `18` | ممنوع | ممنوع |
| `LinkedIn` | `16` | ممنوع | `B2` فقط، `16+` |

**قاعدة:** الأكاديمية **لا تنشئ** أى حساب لأى طفل. الحساب ينشئه ولى الأمر بإيميله. الأكاديمية لا تحتفظ بأى كلمة سر.

### 1.2 المحتوى المنشور عاما — `GitHub Pages`

قائمة فحص إلزامية قبل أول رفع — المدرس يراجع ويوقع فى ورقة الجلسة:

- [ ] الاسم الأول أو اسم مستعار فقط — لا اسم كامل
- [ ] لا اسم مدرسة
- [ ] لا عنوان ولا رقم تليفون ولا إيميل
- [ ] لا صور له أو لأى شخص حقيقى
- [ ] لا روابط لحسابات تواصل اجتماعى شخصية
- [ ] المحتوى مناسب — لا عنف ولا إساءة

**اسم الريبو:** اسم المشروع مش اسم الطفل. مثال: `my-space-page` مش `ahmed-mohamed`.

### 1.3 التصوير

- الكاميرا على **الشاشة والطفل من الكتف** — لا لقطات وجه قريبة إلا لمن وافق على (ب).
- لا تصوير أطفال بلا موافقة (أ) على الأقل.
- الفيديوهات تخزن على جهاز الأكاديمية، لا على موبايل المدرس الشخصى.
- يحذف فيديو أى طفل عند طلب ولى الأمر خلال `48` ساعة.

### 1.4 داخل الجلسة

- المدرس لا يكون وحده مع طفل فى غرفة مقفولة. ركن التصوير فى نفس الغرفة.
- لا تواصل مباشر بين المدرس والطفل خارج الجلسة — التواصل مع ولى الأمر فقط.
- الأجهزة تفتح على المشروع فقط. أى تصفح خارج ذلك يوقف فورا بهدوء.
- أرقام طوارئ الأطفال فى شنطة المدرس ورقيا.

### 1.5 الأمان الرقمى — ما يعلم للطفل

فى بلوك `digital-safety` (`S04`):
- ما تقولش اسمك الكامل ولا مدرستك ولا عنوانك على النت
- كلمة السر سر — حتى من أعز صاحب
- لو حد على النت طلب منك حاجة مضايقاك، قول لكبير فورا
- اللى بتنشره بيفضل — البصمة الرقمية

## 2. نموذج الموافقة — التصوير

```
نموذج موافقة ولى الأمر — أكاديمية 4U

اسم الطفل: __________________   المستوى: ______
اسم ولى الأمر: ______________   التليفون: ______

خلال المستوى، بنصور مقابلة قصيرة (٥ دقايق) مع كل طفل
وهو بيشرح مشروعه. الغرض الأساسى تقييم تعلمه.

من فضلك اختار — كل بند منفصل عن التانى:

☐ (أ) أوافق على تصوير طفلى للتقييم الداخلى.
       الفيديو يحفظ عند الأكاديمية ويرسل لى فقط. لا ينشر.

☐ (ب) أوافق على استخدام مقاطع من الفيديو فى مواد
       الأكاديمية التسويقية (موقع، صفحات تواصل).

☐ لا أوافق على التصوير. المقابلة تتم بدون كاميرا.

ملاحظة: يمكن سحب أى موافقة فى أى وقت برسالة،
ويحذف المحتوى خلال ٤٨ ساعة.

التوقيع: __________________   التاريخ: __________
```

## 3. نموذج الموافقة — حساب `GitHub` (مسار `B` فقط)

```
موافقة إنشاء حساب GitHub — أكاديمية 4U

اسم الطفل: __________________   تاريخ الميلاد: ______

فى الجلسة ١٢ هيرفع طفلك موقعه على GitHub Pages —
خدمة مجانية بتخلى الموقع على رابط حقيقى.

الحساب:
• ينشئه ولى الأمر بإيميله (خطوات مرفقة، ١٠ دقايق)
• الحد الأدنى للسن ١٣ سنة حسب شروط GitHub
• الأكاديمية لا تعرف كلمة السر ولا تحتفظ بها
• الطفل يستخدمه فى الجلسة تحت إشراف المدرس فقط

المحتوى المنشور:
• لا اسم كامل ولا مدرسة ولا صور شخصية — المدرس يراجع قبل الرفع
• الرابط هيبقى بالشكل: username.github.io/project-name

☐ أوافق، وأنشأت الحساب. اسم المستخدم: ______________
☐ طفلى تحت ١٣ — أوافق على نشر موقعه تحت حساب الأكاديمية
   مؤقتا لحين بلوغه ١٣.
☐ لا أوافق. طفلى هيتعلم نفس الخطوات بدون نشر.

التوقيع: __________________   التاريخ: __________
```

## 4. نموذج الموافقة — `ChatGPT` (مسار `B`، اختيارى)

```
موافقة استخدام أداة AI — أكاديمية 4U

فى الجلسة ٨ بنعلم الأطفال يستخدموا أدوات AI
كمساعد للفهم — مش لكتابة الكود بدالهم.

الأساسى: المدرس بيعرض على الشاشة بحسابه. مفيش حساب مطلوب.

اختيارى: لو حابب طفلك يجرب بنفسه:
☐ أوافق على إنشاء حساب ChatGPT لطفلى (١٣+ سنة)
   بإيميلى، لاستخدامه فى الجلسة تحت الإشراف.
☐ لا — يكتفى بالعرض.

قواعد الاستخدام مرفقة (سياسة أدوات AI).

التوقيع: __________________   التاريخ: __________
```

> «أهلا بحضراتكم. قاعدة واحدة عشان راحة الكل: صوروا أطفالكم براحتكم، بس من فضلكم ما تصوروش أطفال غيركم. الأكاديمية بتصور العرض كله، وكل أسرة هيوصلها مقطع طفلها.»
