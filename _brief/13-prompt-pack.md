## `2` — بناء جلسة جديدة

```
ابنى الجلسة <A2-S05> بالكامل.

قبل ما تبدأ:
- اقرا `_brief/04-build-a-session.md` ونفذه خطوة بخطوة.
- اقرا `<track>/<level>/level.md` صف الجلسة دى.
- اقرا الجلسة اللى قبلها والجلسة اللى بعدها عشان التسلسل يبقى سليم.
- اطبع سكربتات ملف المشروع: node _tools/dump-sb3.mjs <الملف>
  وكل رقم واسم هتكتبه لازم يطلع من الخرج ده.

المطلوب تسلمه:
1. sessions/<Sxx>.md كامل بالـ frontmatter
2. slides/<Sxx>.slides.html — انسخ ملف عرض موجود كأساس وامسح الـ sections بس
3. notes/<Sxx>.notes.md — قسم `### جزئية` لكل مفهوم فى concepts_new
   بعدد أمثلة حسب التعقيد (بسيط 2 · متوسط 3 · صعب 4+)
4. تحديث level.md وmanifest.yml
5. قواعد توليد أى ملف checkpoint جديد فى _tools/make-checkpoints.mjs

بعد ما تخلص شغل:
  node _tools/make-checkpoints.mjs
  node _tools/validate.mjs
  node _tools/render-deck.mjs <deck> _review/.render/<id>
وافتح كل صورة شريحة وافحصها بصريا، وقولى إيه اللى شفته.

ما تسلمش قبل ما validate يعدى وتفحص الشرائح صورة صورة.
```

## `4` — إصلاح من تقرير مراجعة

```
اقرا `_review/<id>.md` كله الأول.

بعدين:
1. صنف النقاط: إصلاح فى ملف الجلسة · فى القالب (بينتشر للكل) ·
   فى ملف مشروع · فى بنك مشترك.
2. اكتب سكربت إصلاح `_review/.fix/fix-<id>.cjs` بالنمط الموجود فى
   `_brief/09-tools.md` — لازم يكون idempotent.
3. الإصلاحات فى القالب: عدل `_templates/session.slides.html` ثم sync-slides.mjs
4. الإصلاحات فى ملفات المشروع: عدل قاعدة التوليد ثم make-checkpoints.mjs
5. شغل validate.mjs ثم امسح التشكيل.

لو فيه نقطة إنت شايفها غلط — **ما تنفذهاش**، واكتب ليه فى ردك.
```

## `7` — لما تلاقى تناقض

```
لقيت تناقض بين <الملف A> و<الملف B> فى <الموضوع>.

قبل ما تصلح:
1. افتح ملف المشروع الفعلى واعرف الحقيقة (dump-sb3.mjs أو قراءة index.html).
2. الملف الفعلى هو الحكم — المواد بتتصلح عليه، مش العكس،
   إلا لو الملف نفسه غلط تعليميا (وقتها عدل قاعدة التوليد).
3. صلح **كل** المواضع اللى فيها التناقض — الخطة والشرائح والملاحظات وlevel.md
   وmedia-manifest.md.
```

## `8` — الرد على المؤسس

المؤسس بيقرا عربى وبيكره الكلام الكتير. القواعد:

```
- عامية مصرية. نقط قصيرة. مفيش جداول فى الرد العربى.
- كل جملة تبدأ بحرف عربى.
- كل كلمة إنجليزى فى backticks.
- علامات الترقيم عربية: ، ؛ ؟
- أى أمر أطول من كلمة على سطر مستقل أو فى code block.
- فى الشغل الطويل: قائمة مهام بعلامات [x] و[ ] وسطر عن اللى شغال فيه دلوقتى.
- افترض وأعلن بدل ما تسأل، إلا لو القرار بيغير الشغل جوهريا.
```
