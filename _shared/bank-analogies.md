# بنك التشبيهات والموجات الدلالية

> لكل مفهوم: **موجة دلالية** لبلوك الافتتاح + **ثلاثة أمثلة** لبلوك الشرح.
> الأمثلة بالترتيب دائما: `1` يومى · `2` لعبة أو تطبيق · `3` من داخل الكود.
> المدرس يختار الأنسب لفوجه **ويذكر اختياره**، والباقى احتياطى.

## مسار `A`

### `AN-sequence` — التسلسل
**الموجة:** فكك: «بتعمل إيه الصبح بالترتيب؟» ← استكشف: `UP-01` أو `UP-02` ← أعد التركيب: «الترتيب ده اسمه `sequence` — التسلسل. الكمبيوتر بينفذ بلوك ورا بلوك بالترتيب اللى إنت حاطه.»

| # | المثال | الصياغة |
| --- | --- | --- |
| `1` | الساندويتش | «لو حطيت الجبنة قبل ما تفتح العيش؟ الترتيب فارق. الكود نفس الحاجة.» |
| `2` | لعبة الفيديو | «فى أى لعبة، الشخصية بتنط **بعد** ما تضغط الزرار — مش قبله. الترتيب مبرمج.» |
| `3` | الكود | «البلوك اللى فوق بيشتغل الأول. لو حطينا `say` قبل `move`، هيتكلم وبعدين يتحرك.» |

### `AN-broadcast` — الرسالة — `A2-S02`
**الموجة:** فكك: «لو عايز تقول حاجة لكل اللى فى الفصل مرة واحدة، تعمل إيه؟ تنادى بصوت عالى.» ← استكشف: `UP-21` ← أعد التركيب: «`broadcast` نداء. كل السبرايتات بتسمعه، وكل واحد اللى مستنى النداء ده بيتحرك. اللى مش مستنيه مايعملش حاجة.»

| # | المثال | الصياغة |
| --- | --- | --- |
| `1` | الميكروفون فى المدرسة | «الناظر بينادى «الصف الخامس ينزل». كل المدرسة سمعت، بس الخامس بس اللى نزل. النداء واحد والمستقبلين معروفين.» |
| `2` | الجرس | «جرس الفسحة بيرن. المدرس يقفل الكتاب والطفل يجرى والبواب يفتح الباب. **نداء واحد، تلات ردود مختلفة.**» |
| `3` | الكود | «`broadcast (grow)` من الزرار. الجنية بتكبر، والعصا نفسها بتشغل صوت. **رسالة واحدة، مستقبلين اتنين.**» |
| `4` | الاسم بالحرف | «لو ناديت «يا أحمد» وهو اسمه «أحمد على» — هيرد. لكن الكمبيوتر لأ. `grow` مش `groww` ولا `Grow`. الاسم بالحرف.» |

### `AN-if` — الشرط — `A2-S04`
**الموجة:** فكك: «الصبح بتبص من الشباك. بتقرر تاخد الشمسية على أساس إيه؟» ← استكشف: `UP-22` ← أعد التركيب: «سألت سؤال إجابته صح أو غلط، وعملت حاجة **لو** الإجابة صح. ده `if`.»

| # | المثال | الصياغة |
| --- | --- | --- |
| `1` | المطر | «**لو** الدنيا بتمطر، **يبقى** خد الشمسية. مابتمطرش؟ ماتاخدش. سؤال وإجابته صح أو غلط.» |
| `2` | اللعبة | «**لو** لمست العدو، **يبقى** تخسر حياة. مالمستش؟ مايحصلش حاجة. اللعبة بتسأل السؤال ده آلاف المرات فى الثانية.» |
| `3` | الشكل السداسى | «بص على الفتحة فى بلوك `if` — سداسية مش مستطيلة. البلوكات اللى بتدخل فيها شكلها سداسى برضه. الشكل بيقولك: **ده سؤال، مش رقم.**» |
| `4` | الكود | «`if <touching (Dragonfly)?> then hide` — الحشرة بتسأل «أنا ملامس اليعسوب؟» لو أيوة تختفى. لو لأ تكمل طيران.» |

### `AN-variable` — المتغير — `A2-S06`
**الموجة:** فكك: «لما تلعب وتجمع نقط، النقط دى متسجلة فين؟» ← استكشف: `UP-23` — «العداد البشرى» ← أعد التركيب: «فى صندوق ليه اسم. الصندوق ده اسمه `variable` — المتغير.»

| # | المثال | الصياغة |
| --- | --- | --- |
| `1` | الحصالة | «الحصالة صندوق ليه اسم «فلوسى». بتحط فيها وبتعد. الرقم بيفضل جواها حتى لما تسيبها.» |
| `2` | عداد اللعبة | «الرقم فى ركن الشاشة. بيزيد لما تجمع عملة. اللعبة فاكراه — عشان محفوظ فى متغير.» |
| `3` | الفرق بين `set` و`change` | «`set beats to 0` = **فضى الحصالة وابدأ من الصفر.** `change beats by 1` = **حط جنيه كمان.** أكتر غلطة بتحصل: حد يستخدم `set` مكان `change` فالرقم مابيزيدش أبدا.» |
| `4` | الاسم | «لو سميت الصندوق `x` مش هتفتكر هو إيه بعد أسبوع. سميه `beats` أو `total`. الاسم للبنى آدم مش للكمبيوتر.» |

### `AN-sensing` — الاستشعار — `A2-S04`
**الموجة:** فكك: «إنت قافل عينك. إزاى تعرف إن حد قرب منك؟» ← استكشف: طفل يقف وعينه مقفولة وزميله يقرب — إمتى حس؟ ← أعد التركيب: «إنت عندك حواس بتشتغل لوحدها. السبرايت مالوش. لازم **تسأله**: «إنت ملامس حاجة؟» — والسؤال ده اسمه `sensing`.»

| # | المثال | الصياغة |
| --- | --- | --- |
| `1` | باب المول | «الباب بيفتح لوحده. مين قاله؟ حساس بيسأل كل لحظة «فيه حد قدامى؟». `touching` نفس الحساس.» |
| `2` | لمس بعض | «لو إيدك لمست الحيطة تحس. السبرايت مالوش إحساس — لازم **تسأله** بـ `touching`.» |
| `3` | الكود — `S04` | «`touching (Dragonfly)?` — الحشرة بتسأل «أنا ملامس اليعسوب؟». الإجابة صح أو غلط، وبتتحط فى الفتحة السداسية.» |
| `4` | الكود — `S05` | «`touching color (أخضر)?` بيسأل عن **لون** مش عن سبرايت — أدق بكتير لما تكون عايز جزء معين مش الشخصية كلها.» |

### `AN-operator` — المقارنة — `A2-S04`
**الموجة:** فكك: «إزاى تعرف مين أطول فيكم؟» — اتنين يقفوا جنب بعض ← استكشف: «قارنتوا. والإجابة كانت إيه؟ «أيوه» أو «لأ» — مافيش تالت» ← أعد التركيب: «المقارنة سؤال إجابته صح أو غلط. والكمبيوتر بيقارن بنفس الطريقة.»

| # | المثال | الصياغة |
| --- | --- | --- |
| `1` | القد | «الاتنين نفس الطول بالظبط؟ ده `=`. واحد أطول؟ ده `>`. المقارنة إجابتها صح أو غلط دايما.» |
| `2` | الفم المفتوح | «علامة `>` زى فم بيفتح ناحية الأكبر. `10 > 3` — الفم مفتوح ناحية العشرة. لو اتلخبطت، فكر فى الفم.» |
| `3` | الكود — `S04` | «`if <(size) = (100)>` — اليعسوب وصل حجمه الكامل؟ **بالظبط `100`** — مش `99` ولا `101`.» |
| `4` | الكود — `S07` | «`if <(beats) > (9)>` — عندك أكتر من `9`؟ يبقى تقدر تشترى. `9` بالظبط؟ **لأ** — `>` مش `≥`.» |

### `AN-parallax` — البارالاكس والمنظور — `A3-S02`
**الموجة:** فكك: «إنت راكب عربية وبتبص من الشباك. الشجر اللى جنبك بيعدى بسرعة، والجبل البعيد ساكت تقريبا. ليه؟» ← استكشف: `UP-25` — الصفين الماشيين ← أعد التركيب: «القريب بيعدى أسرع من البعيد. الحيلة دى اسمها `parallax`، وبيها الشاشة المسطحة بتبان ليها عمق.»

| # | المثال | الصياغة |
| --- | --- | --- |
| `1` | شباك العربية | «الشجر جنبك بيطير، والجبل البعيد ماشى معاك. مش الجبل بطىء — هو بعيد. عينك بتترجم فرق السرعة لـ **بعد**.» |
| `2` | القمر | «القمر ماشى معاك وإنت راكب. مش بيتبعك — هو بعيد أوى فحركته على عينك تقريبا صفر.» |
| `3` | البعيد أصغر وأعلى | «بص لشارع طويل: العربية البعيدة بتبان **أصغر وأعلى** فى الصورة. علشان كده لما الروڤر يطلع فوق بنصغره — طلوع = بعد.» |
| `4` | الكود — `S03` | «التلال `change x by (3)` والشجرة `change x by (6)` — نفس الرسالة والاتنين بيتحركوا، بس الشجرة **الضعف**. ده كل سر البارالاكس: رقمين مختلفين.» |

### `AN-clone` — الكلون — `A3-S06`
**الموجة:** فكك: «قالب البسكويت. بتقص بيه كام قطعة؟» ← استكشف: `UP-29` — القالب والقطع ← أعد التركيب: «القالب واحد والقطع كتير، وكل قطعة بعد كده ليها حياتها — دى تتاكل ودى تتحرق. الكلون كده: بيتولد من الأصل، وبعدين بيعيش لوحده.»

| # | المثال | الصياغة |
| --- | --- | --- |
