## المبدأ الحاكم فى البنية

**المحتوى المتكرر يعيش فى مكان واحد، والجلسة بتشير له بمعرف.**

- تشبيه لمفهوم `loop`؟ فى `_shared/bank-analogies.md` بمعرف `AN-loop`. الجلسة بتقول «استخدم `AN-loop`» مش بتنسخه.
- عدلت التشبيه؟ اتعدل فى كل الجلسات اللى بتستخدمه.
- نفس الشىء للأنشطة غير الموصولة (`UP-xx`)، ومسائل `Parsons` (`PS-xx`)، وتحديات `Debug` (`DB-xx`)، والمصطلحات (`G-xxx`).

## كيف تضيف جلسة

1. انسخ `_templates/session.md` و`session.notes.md` و`session.slides.html`.
2. املأ الـ `front-matter`: المعرف، المستوى، الترتيب، المشروع، المفاهيم، المتطلبات السابقة.
3. اختر من البنوك بالمعرف. لو محتاج عنصر مش موجود، **ضيفه للبنك أولا** ثم أشر له.
4. أضف الجلسة لـ `manifest.yml`.
5. شغل التحقق:

```
node _tools/validate.mjs
```

## قواعد الكتابة

- المواد للأطفال بالعربية العامية المصرية المبسطة. المصطلح التقنى إنجليزى بين `backticks` ومعه نطقه العربى من المسرد.
- كل رقم زمنى بالدقائق. كل جلسة `90` بالظبط.
- كل شريحة فيها صورة لازم يكون ليها وظيفة تفسيرية مذكورة فى `notes`.
- الأمثلة الثلاثة: يومى · لعبة أو تطبيق · من داخل الكود. بالترتيب ده.
- **افتراض:** تكتب صراحة أمام أى رقم أو قرار بلا مصدر.
