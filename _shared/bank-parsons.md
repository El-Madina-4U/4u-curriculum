# بنك مسائل `Parsons`

> بطاقات كود مبعثرة، الطفل يرتبها. تطبع وتقص مسبقا — ظرف لكل زوج.
> `PS-A-xx` لمسار `Scratch` · `PS-B-xx` للويب.
> **الحل** مكتوب للمدرس فقط. **المشتت** = بطاقة زيادة لا مكان لها.
> بيبدأ من `S06` فى مسار `A` (سن `10–12`) ومن `S05` فى مسار `B` (سن `13–16`).

---

## مسار `A` — `Scratch`

البطاقات مطبوعة **بشكل البلوكات** — لونها ونصها كما فى `Scratch`. الطفل يرتبها على الترابيزة.

### `PS-A-01` — القطة تتكلم
- **المفهوم:** التسلسل والإيفنت
- **الاستخدام:** `A1-S02` · **ويتعاد فى `A2-S01`** كمسألة تشخيص
- **البطاقات:** `when green flag clicked` · `say Hello! for 2 seconds` · `say I'm a cat for 2 seconds`
- **الحل:** الإيفنت ← `Hello` ← `I'm a cat`
- **المشتت:** لا

### `PS-A-02` — تفكير ثم كلام
- **المفهوم:** `think` قبل `say` و`wait`
- **الاستخدام:** `A1-S03`
- **البطاقات:** `when this sprite clicked` · `think Hmm... for 1 seconds` · `wait 1 seconds` · `say I know! for 2 seconds`
- **الحل:** الإيفنت ← `think` ← `wait` ← `say`
- **المشتت:** لا

### `PS-A-03` — الأتوبيس يمشى
- **المفهوم:** اللوب والحركة
- **الاستخدام:** `A1-S04` · **ويتعاد فى `A2-S01`** كمسألة تشخيص
- **البطاقات:** `when green flag clicked` · `repeat 10` · `move 10 steps` · `wait 0.1 seconds` · [نهاية اللوب]
- **الحل:** الإيفنت ← `repeat` { `move` ← `wait` }
- **المشتت:** لا

### `PS-A-04` — المشى بالكوستيوم
- **المفهوم:** لوب + كوستيوم = أنيميشن
- **الاستخدام:** `A1-S05`
- **البطاقات:** `when green flag clicked` · `forever` · `next costume` · `move 5 steps` · `wait 0.2 seconds` · [نهاية]
- **الحل:** الإيفنت ← `forever` { `next costume` ← `move` ← `wait` }
- **المشتت:** لا — الترتيب داخل اللوب مرن، يقبل أى ترتيب

### `PS-A-05` — ابدأ من البداية
- **المفهوم:** تهيئة قبل اللوب
- **الاستخدام:** `A1-S06`
- **البطاقات:** `when green flag clicked` · `go to x: -200 y: 0` · `repeat 20` · `move 10 steps` · [نهاية] · **مشتت:** `say Hello! for 2 seconds`
- **الحل:** الإيفنت ← `go to` ← `repeat` { `move` }
- **المشتت:** `say` — لا مكان له فى «الأتوبيس يمشى من الشمال»

### `PS-A-06` — عينين تتبع الماوس
- **المفهوم:** `forever` + `point towards`
- **الاستخدام:** `A1-S08` احتياطى · `A1-S09` بديل
- **البطاقات:** `when green flag clicked` · `set rotation style all around` · `forever` · `point towards mouse-pointer` · [نهاية] · **مشتت:** `repeat 10`
- **الحل:** الإيفنت ← `set rotation style` ← `forever` { `point towards` }
- **المشتت:** `repeat 10` — العين لازم تتبع للأبد مش `10` مرات

### `PS-A-07` — المفاجأة
- **المفهوم:** التسلسل الطويل والتوقيت
- **الاستخدام:** `A1-S10` · **ويتعاد فى `A2-S01`** كمسألة تشخيص
- **البطاقات:** `when green flag clicked` · `hide` · `wait 3 seconds` · `show` · `say Boo! for 2 seconds` · **مشتت:** `forever`
- **الحل:** الإيفنت ← `hide` ← `wait` ← `show` ← `say`
- **المشتت:** `forever` — المفاجأة بتحصل مرة واحدة

### `PS-A-09` — الببغاء المزعج
- **المفهوم:** `forever` + التهيئة قبل اللوب
- **الاستخدام:** `A1-S07`
- **البطاقات:** `when green flag clicked` · `set rotation style left-right` · `forever` · `move 10 steps` · `if on edge, bounce` · `next costume` · [نهاية] · **مشتت:** `repeat 10`
- **الحل:** الإيفنت ← `set rotation style` ← `forever` { `move` ← `bounce` ← `next costume` } — الترتيب داخل اللوب مرن
- **المشتت:** `repeat 10` — الببغاء لازم يفضل طول اللعبة
- **نقطة النقاش:** «ليه `set rotation style` **قبل** اللوب مش جواه؟» — بيتعمل مرة واحدة. جوه اللوب هيتعمل مليون مرة بلا داعى.

### `PS-A-11` — التأثير بيراكم
- **المفهوم:** `change` مقابل `set` عند الضغط
- **الاستخدام:** `A1-S09`
- **البطاقات:** `when this sprite clicked` · `change color effect by 25` · [نهاية] · **مشتت:** `set color effect to 25`
- **الحل:** الإيفنت ← `change color effect by 25`
- **المشتت:** `set color effect to 25` — هيثبت نفس اللون كل ضغطة. نقطة النقاش: «ليه `change` مش `set`؟»

### `PS-A-10` — المفاجأة بسبرايتين
- **المفهوم:** تزامن سبرايتين بـ `wait` — `hide` فى واحد و`show` فى التانى بنفس الوقت
- **الاستخدام:** `A1-S11`
- **البطاقات — مجموعتان بلونين:** 🟦 الشىء: `when flag clicked` · `show` · `wait 5` · `hide` — 🟩 المفاجأة: `when flag clicked` · `hide` · `wait 5` · `show` · **مشتت:** `wait 2` (رمادى)
- **الحل:** كل مجموعة سكربت. الرقم `5` فى الاتنين — نفس اللحظة
- **المشتت:** `wait 2` — لو استخدمها فى واحد بس، المفاجأة تظهر والشىء لسه موجود
- **نقطة النقاش:** «الشىء بيختفى والمفاجأة بتظهر فى **نفس** الثانية. لو الأرقام مختلفة يحصل إيه؟»

### `PS-A-08` — قلب الصفحة
- **المفهوم:** الإيفنت على السبرايت + تغيير الخلفية
- **الاستخدام:** `A1-S14` بلوك التثبيت (واحتياطى فى `A1-S12` و`A1-S13`) · **ويتعاد فى `A2-S01`** كمسألة تشخيص
- **البطاقات:** `when this sprite clicked` · `next backdrop` · `start sound page-flip` · **مشتت:** `when green flag clicked`
- **الحل:** `when this sprite clicked` ← `start sound` ← `next backdrop` — **والترتيب المعكوس مقبول برضه**. اسأل الزوج: «الفرق هيبان إمتى؟» (الصوت يبدأ مع التقليب ولا بعده بلحظة؟)
- **المشتت:** `when green flag clicked` — الصفحة تتقلب بالضغط عليها مش بالعلم

### `PS-A-12` — النداء والرد
- **المفهوم:** `broadcast` و`when I receive` — سكربتان على سبرايتين
- **الاستخدام:** `A2-S02`
- **البطاقات — مجموعتان بلونين:** 🟦 الزرار: `when this sprite clicked` · `broadcast (grow)` — 🟩 الجنية: `when I receive (grow)` · `change size by (10)` · **مشتت:** `when green flag clicked` (رمادى)
- **الحل:** الزرار بيبعت، الجنية بتستقبل. اللونان بيقولوا إن دول سكربتان منفصلان على سبرايتين.
- **المشتت:** `when green flag clicked` — الرسالة بتيجى من الضغط على الزرار، مش من العلم
- **سؤال بعد الحل:** «العصا كمان بتستقبل نفس الرسالة. طيب لو عايز سبرايت **تالت** يرد عليها — تضيف بطاقة إيه وفين؟»

### `PS-A-13` — الحشرة اللى بتتاكل
- **المفهوم:** `if` + `touching` جوه `forever`
- **الاستخدام:** `A2-S05` — بلوك التثبيت فى `S04` محجوز لبلوك المهارة (الأمان الرقمى)
- **البطاقات:** `when green flag clicked` · `forever` · `if <touching (Dragonfly)?> then` · `hide` · `go to (random position)` · `wait (1) seconds` · `show` · [نهاية] · **مشتت:** `stop all`
- **الحل:** اللوب برة، الشرط جواه، والأربع بلوكات جوه الشرط بالترتيب ده.
- **المشتت:** `stop all` — الحشرة بتختفى وترجع، اللعبة مابتقفش
- **الفخ:** لو حطوا `if` برة `forever` — يشتغل مرة واحدة بس. اسأل: «الحشرة هتتاكل كام مرة كده؟»

### `PS-A-14` — العداد
- **المفهوم:** `set` عند البداية و`change` عند الحدث — سكربتان
- **الاستخدام:** `A2-S06` · **ويتعاد فى `A2-S14`** كبلوك تثبيت
- **البطاقات — مجموعتان بلونين:** 🟦 الستيج: `when green flag clicked` · `set [beats v] to (0)` — 🟩 الطبلة: `when this sprite clicked` · `play drum (1) for (0.25) beats` · `change [beats v] by (1)` · **مشتت:** `set [beats v] to (1)` (رمادى)
- **الحل:** التصفير مرة واحدة عند العلم، والزيادة كل ضغطة.
- **المشتت:** `set beats to 1` — الرقم هيفضل `1` مهما ضغطت. **ده أهم مشتت فى المستوى**
- **سؤال بعد الحل:** «شيل بطاقة `set beats to 0` — إيه اللى هيحصل تانى لعبة؟»

### `PS-A-15` — الشراء
- **المفهوم:** `if / else` مع مقارنة
- **الاستخدام:** `A2-S07`
- **البطاقات:** `when this sprite clicked` · `if <(beats) > (9)> then` · `change [beats v] by (-10)` · `broadcast (snare)` · `hide` · `else` · `say [محتاج beats أكتر!] for (2) seconds` · [نهاية] · **مشتت:** `set [beats v] to (-10)`
- **الحل:** الإيفنت ← `if` ← جواه **بالترتيب ده**: `hide` ثم `change beats by (-10)` ثم `broadcast (snare)` ← `else` ← الرسالة. (`hide` الأول عشان الزرار مايتضغطش تانى قبل ما الخصم يتم — ده ترتيب `P3-final` بالحرف.)
- **المشتت:** `set beats to -10` — ده بيحط سالب عشرة مكان الرصيد كله بدل ما يخصم منه
- **سؤال بعد الحل:** «عندك `9` بالظبط — هتقدر تشترى؟» (لأ — `>` مش `≥`)

### `PS-A-16` — الترتيب الصح
- **المفهوم:** الشروط المتداخلة وترتيبها
- **الاستخدام:** `A2-S11`
- **البطاقات:** `forever` · `if <(size) = (landed)> then` · `if <touching color (لون المنصة)?> then` · `go to (Platform)` · `else` · `if <touching color (لون الخطر)?> then` · `broadcast (stop)` · `stop [other scripts in sprite]` · [نهايات]
- **الحل:** الحارس الأول (`size = landed` يعنى مش فى الهوا)، وجواه المنصة الأول، والخطر فى `else`.
- **المشتت:** لا — الصعوبة فى الترتيب نفسه
- **سؤال بعد الحل:** «الشخصية واقفة على منصة **بتتحرك**، ووصلت حرفها فبقت لامسة المنصة والخطر مع بعض. لو فحصت الخطر الأول — يحصل إيه؟» (تخسر ظلما)
- **⚠️ اتقاس من الملف:** اسم الرسالة `stop` — **مش `lose`**. الرسائل الموجودة فى `P5-example-custard` هى `start` و`stop` بس.

## مسار `B` — الويب

البطاقات سطور كود مطبوعة بخط `monospace`. الطفل يرتبها فوق بعض.

### `PS-B-01` — أول صفحة
- **المفهوم:** بنية الصفحة
- **الاستخدام:** `B1-S02` والجلسة غير الموصولة
- **البطاقات:** `<h1>أهلا</h1>` · `<p>دى أول صفحة ليا</p>` · `<img src="me.png">`
- **الحل:** أى ترتيب مقبول — **الدرس:** الترتيب فى `HTML` = الترتيب على الشاشة. الزوج يقول شكل الصفحة هيبقى إيه حسب ترتيبه
- **المشتت:** لا

### `PS-B-02` — الفتح والقفل
- **المفهوم:** تاج الفتح والقفل
- **الاستخدام:** `B1-S03`
- **البطاقات:** `<p>` · `الفقرة الأولى` · `</p>` · `<p>` · `الفقرة الثانية` · `</p>`
- **الحل:** فتح ← محتوى ← قفل، مرتين
- **المشتت:** لا

### `PS-B-03` — القائمة
- **المفهوم:** `<ul>` و`<li>`
- **الاستخدام:** `B1-S09`
- **البطاقات:** `<ul>` · `<li>🍕</li>` · `<li>🎮</li>` · `<li>⚽</li>` · `</ul>`
- **الحل:** `<ul>` ← العناصر الثلاثة بأى ترتيب ← `</ul>`
- **المشتت:** لا

### `PS-B-04` — قاعدة `CSS`
- **المفهوم:** السيليكتور والخصائص
- **الاستخدام:** `B1-S05`
- **البطاقات:** `h1 {` · `color: purple;` · `font-size: 50px;` · `}` · **مشتت:** `<h1>`
- **الحل:** `h1 {` ← الخاصيتان بأى ترتيب ← `}`
- **المشتت:** `<h1>` — ده `HTML` مش `CSS`

### `PS-B-05` — الكلاس
- **المفهوم:** الكلاس فى `HTML` و`CSS`
- **الاستخدام:** `B1-S06`
- **البطاقات:** `<p class="big">` · `كلام كبير` · `</p>` · `.big {` · `font-size: 40px;` · `}` · **مشتت:** `#big {`
- **الحل:** الـ `HTML` الثلاث ثم الـ `CSS` الثلاث
- **المشتت:** `#big` — ده `id` مش كلاس

### `PS-B-06` — الهوفر
- **المفهوم:** `:hover`
- **الاستخدام:** `B1-S07` · وتتعاد فى `B1-S11` كمراجعة
- **البطاقات:** `.card:hover {` · `transform: scale(1.2);` · `}` · **مشتت:** `.card:click {`
- **الحل:** الثلاثة بالترتيب
- **المشتت:** `:click` — مش موجودة فى `CSS`

### `PS-B-07` — صفحة كاملة
- **المفهوم:** بنية الصفحة الكاملة
- **الاستخدام:** `B1-S10`
- **البطاقات:** `<!DOCTYPE html>` · `<html>` · `<head>` · `<title>صفحتى</title>` · `</head>` · `<body>` · `<h1>أهلا</h1>` · `</body>` · `</html>` · **مشتت:** `<body>` تانية
- **الحل:** الترتيب أعلاه
- **المشتت:** `<body>` مكررة — `body` واحدة بس

### `PS-B-08` — الدورة
- **المفهوم:** دورة النشر — `S14`
- **الاستخدام:** `B1-S14`
- **البطاقات:** «عدلت `index.html` على جهازى» · «فتحت الملف على `GitHub`» · «ضغطت القلم» · «لصقت الكود الجديد» · «كتبت وصف الـ `commit`» · «`Commit changes`» · «استنيت دقيقة» · «`refresh` على الرابط» · **مشتت:** «عملت `repository` جديد»
- **الحل:** الترتيب أعلاه
- **المشتت:** ريبو جديد — الريبو موجود، بنعدل فيه

## قواعد التنفيذ

- ظرف لكل زوج. البطاقات مقصوصة **قبل** الجلسة.
- `8` دقائق ترتيب. زوج يعرض حله على البروجيكتور. تصحيح جماعى.
- **المشتت:** من `S06` فقط. قبلها الطفل بيتعلم الترتيب مش الاستبعاد.
- الطفل يشرح **ليه** الترتيب ده — مش بس يرتب.
