## بناء `1` — الصفحة الأولى

**قاعدة الجلسة:** «صفحة واحدة. اختبر. الصفحة اللى بعدها.» **مش كل الصفحات مرة واحدة.**

**لكل صفحة — النمط:**

| # | الخطوة | البطاقة |
| --- | --- | --- |
| `1` | الخلفية الحقيقية: بدل خلفية `page1` باللى فى خطتك — من المكتبة أو ارسم. **الاسم يفضل `page1`** | `SK-A-11` |
| `2` | السبرايت بتاع الصفحة دى: ضيفه. اسحبه مكانه | `SK-A-01` |
| `3` | السبرايت: `when backdrop switches to page1` ← `show` ← `go to x: y:` | `SK-A-10` |
| `4` | السبرايت: `when backdrop switches to cover` ← `hide` — و`page2` ← `hide` (لو مش هيظهر فيها) | — |
| `5` | السبرايت بيعمل إيه فى الصفحة دى؟ — `say`؟ صوت؟ حركة؟ تحت `show` | `SK-A-02` `SK-A-07` |
| `6` | **جرب:** العلم ← الزرار ← الصفحة `1`؟ السبرايت ظهر؟ عمل حاجته؟ ← الزرار ← اختفى؟ | — |

**ليه `hide` فى الصفحات التانية:** السبرايت لو ظهر مرة بيفضل ظاهر لحد ما حد يخفيه. **كل صفحة لازم تقرر.**

## بناء `2` — الصفحة الثانية والغلاف

نفس النمط للصفحة `2`. ثم الغلاف: اسم الكتاب + الشخص — `Backdrops` ← `cover` ← لو فيه زرار `Convert to Vector` اضغطه الأول ← أداة `T`.

**`checkpoint`:** لو زوج ماوصلش لهنا — `P6-skeleton` + صفحة واحدة كافية للجلسة الجاية.
