# شهادة إتمام المستوى — قالب الطباعة

> تتطبع مرة واحدة قبل `S16` بالأسماء. `12` نسخة.
> الملف الجاهز للطباعة: `_shared/print/certificate.html` — يفتح بأى متصفح ويتطبع `A4` أفقى.

---

## القرارات

| البند | القرار | ليه |
| --- | --- | --- |
| اللغة | **عربى**، والمصطلح التقنى إنجليزى | الشهادة لولى الأمر مش للطفل بس |
| الحجم | `A4` أفقى، شهادة واحدة فى الصفحة | تتعلق على الحيطة |
| الاسم | **بخط اليد بقلم جاف أزرق** | مكتوبة بالكمبيوتر بتبان جماعية؛ بخط الإيد بتبان شخصية |
| التاريخ | الشهر والسنة بس — مش يوم | لو العرض اتأجل مايبقاش فيه تناقض |
| التوقيع | المدرس **بإيده** | ده اللى بيدى الورقة قيمة |
| اللى الطفل عمله | **جملة واحدة محددة عن مشروعه هو** — مش نص عام | «عمل محاكاة لقطة بتجوع» أوقع من «أتم المستوى بنجاح» |

**القاعدة الحاكمة:** الشهادة بتقول **إيه اللى الطفل عمله**، مش إنه «حضر». لو الجملة تنفع تتقال على أى طفل تانى، يبقى اكتبها تانى.

## النص

```
                    أكاديمية 4U

              شهــادة إتمــام مستـوى

     ..............................................
                  [اسم الطفل بخط اليد]

              أتم المستوى [A1 / A2 / A3 / B1 / B2]

                    [اسم المستوى]

     وبنى بنفسه:  ....................................
                    [جملة واحدة عن مشروعه هو]

     واتعلم:  [تلات كلمات — المفاهيم المحورية للمستوى]


        [الشهر] [السنة]                    ....................
                                             توقيع المدرس
```

---

## «واتعلم» — التلات كلمات لكل مستوى

| المستوى | الكلمات |
| --- | --- |
| `A1` | التسلسل · الإيفنت · اللوب |
| `A2` | التواصل · القرار · الذاكرة |
| `A3` | يملأ عند بناء المستوى |
| `B1` | بنية الصفحة · الشكل · النشر |
| `B2` | يملأ عند بناء المستوى |

## «وبنى بنفسه» — أمثلة للصياغة

| المستوى | مثال صح | مثال غلط |
| --- | --- | --- |
| `A1` | «كتاب تفاعلى عن الفضاء، `4` صفحات بتتقلب بالضغط» | «مشروع سكراتش» |
| `A2` | «محاكاة لقطة بتجوع كل `10` ثوانى والمستخدم بيأكلها» | «لعبة بالمتغيرات» |
| `B1` | «صفحة عن كورة القدم منشورة على رابط بيفتح من الموبايل» | «موقع إلكترونى» |

**المدرس بيكتب الجملة دى وهو بيراجع دفتر التصميم قبل `S16` — مش فى اللحظة الأخيرة.**

## التجهيز

- [ ] `12` نسخة مطبوعة **فاضية الاسم والجملة** — قبل `S16` بيومين
- [ ] المدرس يملا الاسم والجملة بخط اليد ويوقع — قبل الجلسة، مش قدام الأهل
- [ ] ورق `160` جرام على الأقل. الورق العادى بيبان رخيص وبيتكرمش
- [ ] نسخة زيادة أو اتنين — طفل جديد أو ورقة اتقطعت
