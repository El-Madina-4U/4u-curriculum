# `B1-S06` — الكارت: صندوق جوه صندوق 🃏

> **المشروع:** `Flip treat webcards` — الجلسة `A` من `2`
> **المرحلة:** `Explore`
> **الناتج بنهاية الجلسة:** كارت بصورة حلوى ووصف — ببنية ثلاث طبقات جاهزة للقلب. القلب نفسه الجلسة الجاية.

---

## الهدف

بنهاية الجلسة الطالب يقدر يستخدم `<div>` كصندوق يجمع عناصر، يبنى بنية متداخلة بكلاسات، يفهم الفرق بين `padding` و`margin`، ويغير `<title>` الصفحة.

## المفاهيم

| المفهوم | جديد؟ | المسرد |
| --- | --- | --- |
| `<title>` — اسم التاب | **جديد** | `G-249` |

| الصناديق المتداخلة — `card` ← `card-content` ← `card-face` | **جديد** | — |
| `padding` مقابل `margin` | **جديد** | `G-222` `G-223` |
| `border` — الإطار الأحمر | **جديد** | `G-224` |

## خلص بدرى / اتعثر

- **خلص بدرى:** «`width` و`height` فى `.wrap .card` — غيرهم و`F5`.» ثم: «لون الإطار وسمكه — `red` ← `blue`، و`5px` ← `15px`.» ثم: «`<title>` بالعربى.»
- **اتعثر:** البطاقة ← الزميل ← `P3-after-A` ← الأسئلة الأربعة. **الخطوات `6–7` (اللف) أصعب حتة** — «اكتب `<div class="card">` **فوق** الصورة، و`</div>` **تحت** الوصف.»
