نجرب

نغير حتة واحدة — يحصل إيه؟

  • 2 ← infinite؟
  • 8s ← 1s؟
  • linear ← ease؟
كلمة جديدة
@keyframes
كى فريمز
@keyframes rotate-center {
  0%   { transform: rotate(0); }
  100% { transform: rotate(360deg); }
}

من إيه لإيه. البداية والنهاية. المتصفح بيحسب اللى بينهم.

فكروا

360deg ← 180deg يحصل إيه؟

ولو 0% و100% بقوا نفس الحاجة؟

جربت Scratch قبل كده؟

Scratch

forever
  turn 15
  wait 0.1

CSS

animation: rotate-center
  linear 8s 2;

وماجربتش؟ فكر فى فيلم كارتون: الرسام بيرسم أول رسمة وآخر رسمة، والباقى بينحسب.
