## بلوك `PRIMM` — تفصيل

**الملف:** `debug/DB-B-03/` — فولدر فيه ملفين: `index.html` (صفحة عنوانها `Top 5 Emojis!` وتحتها `3` عناصر قائمة) و`style.css` وآخر قاعدة فيه:

```css
h1 {
  colour: purple;
}
```

| المرحلة | الدقيقة | ماذا يعرض | السؤال |
| --- | --- | --- | --- |
| `Predict` | `0–3` | `style.css` على الشاشة — **بدون تشغيل** | «العنوان لونه إيه؟ **كل طفل يكتب توقعه فى الدفتر — سطر واحد.**» لف وشوف الدفاتر قبل ما تشغل |
| `Run` | `3–5` | افتح `index.html` — العنوان أسود | «مين توقع بنفسجى؟ مين توقع أسود؟ القاعدة موجودة. ليه مااشتغلتش؟» |
| `Investigate` | `5–10` | `F12` ← `Styles` ← السطر `colour: purple` مشطوب وجنبه مثلث تحذير | «المتصفح مش فاهم `colour`. `CSS` أمريكى — `color`. حرف واحد.» صلح على الشاشة ← `F5` ← بنفسجى |
| `Modify` | `10–18` | افتح `P2-final/style.css` ← `.transparent { opacity: 0.95; }` — تعديل واحد بس: الرقم | «الكلاس ده حد كتبه بإيده — نقطة واسم من اختياره. `0.95` — شايفين الخلفية من ورا المحتوى؟ تقريبا لأ. نغيرها لكام؟» ياخد اقتراح منهم ← يكتب `0.5` ← `F5` ← الإيموجى بانت |
| جسر | `18–20` | — | «الكلاس ده مش موجود فى الملف بتاعكم. النهاردة **إنتم** اللى هتكتبوه.» |

**ملاحظة تنفيذية:** `main` أبيض فوق صفحة بيضا — `0.95` مش هتورى فرق على البروجيكتور. **ابدأ بـ `0.5`** عشان اللحظة تبان.

**الربط:** «النهاردة هتكتبوا الكلاس ده بنفسكم. مش هتستخدموا جاهز.»

## خلص بدرى / اتعثر

- **خلص بدرى:** «`animation.css` ← `.bounceme` ← `2s 3` ← غير العدد والمدة.» ثم: «`@keyframes bounce` ← `-6rem` ← `-12rem` — ينط أعلى.» ثم: «كلاس تانى من عندك: `.rounded { border-radius: 20px; }` على الاقتباس.»
- **اتعثر:** البطاقة ← الزميل ← `P2-after-A` ← الأسئلة الأربعة (السؤال الرابع فى مسار الويب يتقال «أول **سطر** ممكن يكون هو السبب؟» مش «أول بلوك»). **الخطوة `2` هى الأهم** — لو الزوج ماكتبش الكلاس بإيده، اقعد معاه دقيقة.
