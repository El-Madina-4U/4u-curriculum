## بلوك `PRIMM` — تفصيل

**الملف:** `debug/DB-B-01/` — فولدر فيه `index.html` و`style.css`. الباج: `</h1>` ناقص، فالفقرة بقت جوه العنوان وكل الصفحة عنوان كبير.

**قاعدة `Modify`:** `style.css` فيه `h2 { text-align: left; }` — دى اللى هتتغير لـ `center`.

| المرحلة | ماذا يعرض | السؤال |
| --- | --- | --- |
| `Predict` | الكود من بعيد | «الصفحة هتبان إزاى؟» |
| `Run` | كله كبير وعريض | «كله بقى عنوان. ليه؟» |
| `Investigate` | `F12` ← `Elements` ← الفقرة **جوه** `h1` | «شوفوا `F12`: `p` جوه `h1`. المتصفح فاكر العنوان لسه مافتحش. التاج مقفول؟» ← `</h1>` ← حفظ ← `F5` |
| `Modify` | `style.css` ← قاعدة `h2` ← `text-align: left` ← `center` | «القاعدة دى تلات حتت: `h2` — لمين. `text-align` — إيه. `center` — القيمة. غير القيمة.» |

**الربط:** «`F12` بيوريك الغلط. وقاعدة `CSS` = لمين + إيه + القيمة. دلوقتى صفحتكم.»
