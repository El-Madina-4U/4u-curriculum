# `B1-S14` — زائر حقيقى + أول `commit` 🔄

> **المشروع:** `Build a webpage` — `3` من `4` — **التغذية الراجعة والتحديث**
> **المرحلة:** `Invent`
> **الناتج بنهاية الجلسة:** شغل `S13` اترفع أول الجلسة، وكل صفحة اتزارت **على رابطها الحى وهو محدث** من الطالب المكتوب قدام اسمه فى القائمة، اتعدلت بناء على رأيه، **واتعمل لها `commit` تانى — الموقع اتحدث مرتين فى نفس اليوم.**
> **المقابلات المصورة:** الطلبة `1–4`.

---

## الهدف

بنهاية الجلسة الطالب رفع شغله الحقيقى على الرابط، اختبر صفحته على زائر حقيقى **شاف النسخة المحدثة**، عدل بناء على رأيه، **وعاش دورة النشر الكاملة مرتين: تعديل ← `commit` ← الموقع اتحدث.**

## بناء `1` — ارفع الأول، بعدين الزائر

**ليه الرفع قبل الزيارة؟** كل شغل `S13` — المحتوى الحقيقى والصور — لسه على الجهاز المحلى، والرابط الحى لسه بيورى هيكل `S12` بسطوره المؤقتة. لو الزائر فتح الرابط دلوقتى هيملا بطاقة عن صفحة مش موجودة. **مافيش زيارة قبل رفع.**

| الدقيقة | ماذا يحدث |
| --- | --- |
| `0–3` | «افتح صفحتك المحلية (`F5`) على تاب، **وسجل دخول `github.com`** على تاب تانى — كلمة السر من ولى أمرك. مين مانساش؟» — المدرس يبدأ لفة المراجعة |
| `3–6` | **مراجعة نشر — إلزامية** (`safeguarding.md` §1.2): المدرس يمر على `12` شاشة — لا اسم كامل · لا مدرسة · لا عنوان أو تليفون · لا صور شخصية · الصور مصدرها معروف — **ويوقع. اللى مش موقع مايعملش `commit`.** واللى خلص يفتح الريبو ← `index.html` ← القلم ✏️ |
| `6–9` | **`commit` الرفع:** `VS Code` ← `Ctrl+A` ← `Ctrl+C` · `GitHub`: **اضغط جوه الكود** ← `Ctrl+A` ← `Ctrl+V` ← `Commit changes...` ← الوصف: «شغل الجلسة اللى فاتت» ← الزرار الأخضر. ونفس الحاجة لـ `style.css`. صور جديدة؟ `Add file` ← `Upload` |
| `9–10` | «اقفلوا `VS Code`. المتصفح. **الرابط المكتوب قدام اسمك فى القائمة** — مش رابط اللى جنبك. زى أى زائر فى العالم.» |
| `10–20` | تصفح. اضغط كل لينك. صغر المتصفح — الموبايل. **ما تصلحش.** البطاقة |
| `20–22` | «البطاقة على ترابيزة صاحبها.» |
| `22–25` | اقرا بطاقتك. قرر. ابدأ التعديل **على `VS Code`** — محليا |

**مين يزور مين:** حلقة مغلقة مكتوبة **بالأسماء** على قائمة الروابط قبل الجلسة — `1` يزور `2`، `2` يزور `3` … `12` يزور `1`. عمود «هتزور: ___» قدام كل اسم. من غير كده أطراف الصف بتتزار مرتين والنص التانى صفر بطاقات.

## بناء `2` — التعديل والإكمال

التعديل من البطاقة أولا — «مافهمتهاش» الأولوية. ثم الأقسام الناقصة.

| الدقيقة | ماذا يحدث |
| --- | --- |
| `0–15` | التعديل من البطاقة. المقابلتان `3` و`4` فى `0–5` و`6–11` |
| `15` | **المدرس ينادى «بدلوا»** — سائق ← ملاح (`pedagogy.md` §الأزواج) |
| `15–20` | إكمال الأقسام الناقصة |
| `20–23` | **احفظ الكل** — `index.html` و`style.css`. و**مراجعة نشر تانية:** المدرس يمر على اللى اتغير بنفس قائمة `safeguarding` §1.2 ويوقع الخانة التانية. اللى مش موقع مايعملش `commit` فى بلوك المهارة |
| `23–25` | آخر حفظ. اقفل `VS Code`؟ لأ — هنحتاجه فى النسخ |

## بلوك المهارة — `commit` — `15` دقيقة

**`github-track.md` §5.** كل طالب: `index.html` **و**`style.css` لو اتغير. ده الـ `commit` **التانى** النهاردة — الأول كان فى أول بناء `1`.

| الدقيقة | الخطوة | الشريحة |
| --- | --- | --- |
| `0–2` | افتح رابطك — من الدفتر، أو `Settings` ← `Pages` ← السطر `Your site is live at`. «ده اللى رفعته الصبح واللى الزائر شافه. التعديلات اللى بعد البطاقة لسه على جهازك.» | `B-GH-06` |
| `2–4` | لسه داخل على `github.com`؟ الريبو ← اضغط `index.html` ← القلم ✏️ | `B-GH-07` |
| `4–9` | `VS Code` ← `Ctrl+A` ← `Ctrl+C` · `GitHub`: **اضغط جوه الكود الأول** ← `Ctrl+A` ← `Ctrl+V` ← `Commit changes...` (بتلات نقط — **هيفتح صندوق**) ← الوصف: «ضفت قسم ___ وصلحت ___» ← النقطة على `Commit directly to the main branch` ← **الزرار الأخضر** `Commit changes` | `B-GH-08` `B-GH-09` |
| `9–11` | نفس الحاجة لـ `style.css` لو اتغير. صور جديدة؟ `Add file` ← `Upload` — **الأسماء حروف صغيرة** | — |
| `11–13` | استنى دقيقة. `refresh` الرابط. **اتحدث؟** 🎉 تصفيق | — |
| `13–15` | شريحة الدورة: عدل ← `commit` ← الموقع اتحدث. وسؤال: «ليه `commit` كتير مش مرة واحدة فى الآخر؟» | — |

**بلا حساب:** **حساب الأكاديمية مفتوح على جهاز البروجيكتور** (نفس تجهيز `S12`). الطفل ييجى ويعمل الخطوات بنفسه على ريبوه تحت `El-Madina-4U` — المدرس بيدخل كلمة السر بس ومايلمسش الكيبورد بعدها. يشوف رابطه بيتحدث النهاردة زى الكل. (`github-track.md` §7)
