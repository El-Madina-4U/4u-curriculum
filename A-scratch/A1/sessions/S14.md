# `A1-S14` — حد تانى يقرا كتابك 👀

> **المشروع:** `I made you a book` — `3` من `4` — **التغذية الراجعة**
> **المرحلة:** `Invent`
> **الناتج بنهاية الجلسة:** كل كتاب اتقرا من زوج تانى، وكل زوج غير حاجة واحدة على الأقل بناء على اللى سمعه.
> **المقابلات المصورة:** الأطفال `1–4` — أثناء بلوكى البناء، `5` دقايق لكل واحد فى الركن.

---

## الهدف

بنهاية الجلسة الطفل جرب مشروعه على مستخدم حقيقى، سمع رأيه بصيغة محددة، وعدل بناء عليه. **المشروع مابيخلصش لما إنت تقول — بيخلص لما حد تانى يفهمه.**

## بطاقة التغذية الراجعة — تطبع

```
┌─────────────────────────────────────┐
│  قريت كتاب: ___________             │
│  كتبها: _______________             │
│                                     │
│  ⭐ حاجة عجبتنى:                    │
│  _________________________________  │
│                                     │
│  ⭐ حاجة تانية عجبتنى:              │
│  _________________________________  │
│                                     │
│  🌠 أتمنى لو:                       │
│  _________________________________  │
│                                     │
│  ❓ حاجة مافهمتهاش:                 │
│  _________________________________  │
└─────────────────────────────────────┘
```

**القاعدة:** نجمتين **قبل** الأمنية. الأمنية بصيغة «أتمنى لو» مش «ده وحش».

## بناء `1` — التبديل

| الدقيقة | ماذا يحدث |
| --- | --- |
| `0–2` | «كل زوج يحط كتابه بملء الشاشة على العلم. قوموا. الزوج `1` لجهاز `2`، `2` لـ `3`... `6` لـ `1`.» |
| `2–12` | **اقرا الكتاب.** اضغط على كل حاجة. **ما تصلحش حاجة.** املأ البطاقة |
| `12–14` | «ارجعوا لأجهزتكم. البطاقة تتساب على الترابيزة.» |
| `14–25` | اقرا بطاقتك. **قرر:** هتغير إيه؟ ابدأ |

---

## بناء `2` — التعديل والإكمال

- **غير حاجة واحدة على الأقل** من البطاقة. لو «مافهمتهاش» — دى الأولوية.
- كمل الصفحات الناقصة.
- الدقيقة `20`: **احفظ.**
