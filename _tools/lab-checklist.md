## 2. التثبيت — يتعمل فى نفس الزيارة

| البند | ✓/✗ |
| --- | --- |
| `Scratch Desktop` مثبت على كل جهاز — مسار `A` | |
| `VS Code` مثبت على كل جهاز — مسار `B` — بإضافة `Live Server` لو أمكن | |
| فولدر `4U-offline/` منسوخ على كل جهاز: مشاريع المستوى + `checkpoints` + الشرائح | |
| فولدر لكل طفل باسمه على سطح المكتب: `4U-[الاسم]/` | |
| اختبار: فتح `.sb3` من `4U-offline/` — بيشتغل | |
| **اختبار إضافة `Music` — مسار `A3` حرج:** فى `Scratch Desktop` وكابل الشبكة **مفصول**: زرار `Add Extension` تحت شمال ← `Music` ← اسحب `play note (60) for (0.25) beats` واضغط عليه. **لازم يطلع صوت.** لو مطلعش، مشروع `P5` كامل (`4` جلسات) مش هيشتغل | |
| اختبار: صوت خارج من سماعات الجهاز أصلا — مش من سماعة داخلية مكسورة | |
| اختبار: فتح `S01.slides.html` فى المتصفح — بيشتغل والصور ظاهرة | |
| اختبار مسار `B`: فتح `index.html` من `checkpoints` فى المتصفح | |
