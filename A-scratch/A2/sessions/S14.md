# `A2-S14` — حد تانى يجرب محاكاتك 👀

> **المشروع:** `This sprite needs you` — `3` من `4` — **التغذية الراجعة**
> **المرحلة:** `Invent`
> **الناتج بنهاية الجلسة:** كل محاكاة اتجربت من زوج تانى وهو ساكت، وكل زوج غير حاجة واحدة على الأقل بناء على اللى اتكتب فى بطاقة الاختبار.
> **المقابلات المصورة:** الأطفال `1–4` — أثناء بلوكى البناء، `5` دقايق لكل واحد فى الركن.

---

## الهدف

بنهاية الجلسة الطفل جرب محاكاته على مستخدم حقيقى مش عارف عنها حاجة، شاف بعينه هل المتغير بيتغير لوحده ولا لأ، وعدل بناء على اللى شافه.

**النقطة الحاكمة:** الاختبار هنا مش «اللعبة حلوة ولا لأ». الاختبار سؤالين: **الرقم اتغير لوحده؟** و**عرفت تحسنه؟** دول بند `2` وبند `3` من البريف، ومحدش بيكتشف إنهم ناقصين غير لما حد تانى يقعد على الجهاز.

## بطاقة الاختبار — تطبع

```
┌────────────────────────────────────────────┐
│  جربت محاكاة: ______________               │
│  اللى عملوها: ______________               │
│                                            │
│  1. المتغير اللى شفته على الشاشة اسمه:     │
│     __________________                     │
│                                            │
│  2. سيبتها 30 ثانية من غير ما ألمس حاجة.   │
│     الرقم اتغير لوحده؟   ☐ أيوه   ☐ لأ     │
│                                            │
│  3. عملت إيه عشان أحسنه؟                  │
│     __________________________________     │
│     ونفع؟   ☐ أيوه   ☐ لأ                 │
│                                            │
│  ⭐ حاجة عجبتنى:                           │
│     __________________________________     │
│  ⭐ حاجة تانية عجبتنى:                     │
│     __________________________________     │
│  🌠 أتمنى لو:                              │
│     __________________________________     │
│  ❓ حاجة مافهمتهاش:                        │
│     __________________________________     │
└────────────────────────────────────────────┘
```

**القاعدة:** البنود التلاتة الأولى **حقائق** — تتملى بالمشاهدة مش بالرأى. النجمتان **قبل** الأمنية، والأمنية بصيغة «أتمنى لو» مش «ده وحش».

## بناء `1` — التبديل والاختبار

| الدقيقة | ماذا يحدث |
| --- | --- |
| `0–2` | «كل زوج يحط محاكاته بملء الشاشة والمتغير باين، ويضغط العلم. قوموا. الزوج `1` لجهاز `2`، `2` لـ `3`... `6` لـ `1`.» |
| `2–5` | **البند `2` الأول: عد `30` ثانية وإيدك بعيدة عن الماوس.** بص على الرقم. اتغير؟ اكتب |
| `5–11` | دلوقتى العب. جرب تحسن الرقم. اضغط على كل حاجة. **ما تصلحش كود** |
| `11–13` | كمل النجمتين والأمنية. «ارجعوا لأجهزتكم. البطاقة تتساب على الترابيزة» |
| `13–25` | اقرا **البطاقتين اللى على ترابيزتك** — اللى سابهم الزوج اللى جه على جهازكم. **قرر:** هتغير إيه؟ ابدأ |

**ليه العد الأول؟** لو بدأ يلعب على طول، هيلمس حاجة تغير الرقم ومش هيعرف يفرق بين «بيتغير لوحده» و«بيتغير لما ألمس».

## بناء `2` — التعديل والإكمال

- **غير حاجة واحدة على الأقل** من البطاقة. **الترتيب:** «الرقم ما اتغيرش لوحده» أولا، بعدين «مافهمتهاش»، بعدين الأمنية، بعدين الإضافات.
- كمل الناقص من خطة `S12`.
- الدقيقة `20`: **احفظ.**
