# بطاقات المهارات

> مرجع فى إيد الطفل على الترابيزة. بطاقة `A6` مطبوعة ومغلفة لكل مهارة.
> أول مصدر مساعدة عند التعثر — قبل الزميل وقبل المدرس.
> `SK-A-xx` لمسار `Scratch` · `SK-B-xx` للويب.
> كل بطاقة: **اسم** + **متى تستخدمها** + **الخطوات** + **صورة** من `assets/cards/`.

---

## مسار `A` — `Scratch`

### `SK-A-01` — أضيف سبرايت
- **متى:** عايز شخصية جديدة.
- **الخطوات:** تحت يمين الشاشة ← زرار القطة الأزرق ← اختار من المكتبة أو ارسم.
- **صورة:** `SK-A-01.png` — الزرار محوط.

### `SK-A-02` — أخلى السبرايت يتكلم
- **متى:** عايزه يقول حاجة.
- **الخطوات:** فئة `Looks` البنفسجى ← `say Hello! for 2 seconds` ← اكتب كلامك.
- **تذكير:** `say` من غير `for` بيفضل ظاهر لحد ما حاجة تانية تحصل.

### `SK-A-03` — أبدأ السكربت
- **متى:** أى سكربت جديد.
- **الخطوات:** فئة `Events` الأصفر ← `when green flag clicked` ← ركب اللى بعده تحته.
- **تذكير:** لو البلوكات مش لازقة، مش هيشتغل.

### `SK-A-04` — أكرر
- **متى:** نفس الحاجة أكتر من مرة.
- **الخطوات:** فئة `Control` البرتقالى ← `repeat 10` أو `forever` ← حط البلوكات **جوه** الفم.
- **تذكير:** `repeat` بعدد. `forever` لحد ما توقف.

### `SK-A-05` — أحرك السبرايت
- **متى:** عايزه يمشى.
- **الخطوات:** فئة `Motion` الأزرق ← `move 10 steps` ← غير الرقم. سالب معناه للشمال.
- **تذكير:** حطه جوه لوب عشان يفضل يمشى.

### `SK-A-06` — أغير شكله
- **متى:** أنيميشن أو تعبير.
- **الخطوات:** تاب `Costumes` فوق ← ارسم أو اختار ← فى الكود: `next costume` أو `switch costume to`.

### `SK-A-07` — أضيف صوت
- **متى:** عايز صوت.
- **الخطوات:** تاب `Sounds` ← اختار من المكتبة ← فى الكود: فئة `Sound` الوردى ← `start sound`.

### `SK-A-08` — أستنى
- **متى:** بين حاجتين.
- **الخطوات:** `Control` ← `wait 1 seconds` ← غير الرقم. `0.5` = نص ثانية.

### `SK-A-09` — أخليه يتبع الماوس
- **متى:** `Silly eyes`.
- **الخطوات:** `Motion` ← `point towards mouse-pointer` ← جوه `forever`.

### `SK-A-10` — أخفى وأظهر
- **متى:** مفاجأة.
- **الخطوات:** `Looks` ← `hide` ← `wait` ← `show`.

### `SK-A-11` — أغير الخلفية
- **متى:** مشهد جديد أو صفحة جديدة.
- **الخطوات:** تحت يمين ← زرار الخلفية ← اختار. فى الكود: `Looks` ← `switch backdrop to` أو `next backdrop`.

### `SK-A-12` — أخليه يستجيب للضغط
- **متى:** زرار أو صفحة تتقلب.
- **الخطوات:** `Events` ← `when this sprite clicked` ← البلوكات تحته.

### `SK-A-13` — أحفظ شغلى
- **متى:** آخر كل جلسة **وكل `10` دقايق**.
- **الخطوات:** `File` ← `Save to your computer` ← فولدر اسمى ← اسم الملف: `اسم-المشروع.sb3`.
- **تذكير:** مش محفوظ = ضاع.

### `SK-A-14` — ألاقى الغلط
- **متى:** مش شغال زى ما توقعت.
- **الخطوات:** `1` البلوكات لازقة؟ `2` الإيفنت الصح؟ `3` الأرقام صح؟ `4` جوه اللوب ولا براه؟ `5` على السبرايت الصح؟

### `SK-A-15` — أبعت رسالة — `A2-S02`
- **الخطوات:** `Events` ← `broadcast ( )` ← اضغط السهم ← `New message` ← اكتب الاسم.
- **الاستقبال:** عند السبرايت التانى: `when I receive [نفس الاسم]` ← تحته اللى هيحصل.
- **تذكير:** الاسم **بالحرف** عند الباعت والمستقبل. و**أكتر من سبرايت يقدروا يستقبلوا نفس الرسالة** — ده مش غلط، ده الهدف.

### `SK-A-16` — أعمل شرط — `A2-S04`
- **الخطوات:** `Control` ← `if < > then` ← جيب السؤال من `Sensing` أو `Operators` وحطه فى **الفتحة السداسية**.
  ```
  if <touching (Dragonfly)?> then
    hide
  ```
- **تذكير:** الفتحة سداسية يعنى **سؤال** مش رقم. لو البلوك مش داخل، يبقى شكله غلط.
- **عشان يفضل يسأل:** حط الـ `if` جوه `forever` — الشرط لوحده بيتفحص مرة واحدة بس.

### `SK-A-17` — أعمل متغير — `A2-S06`
- **الخطوات:** `Variables` ← `Make a Variable` ← الاسم ← `For all sprites` ← `OK`.
- **الاستخدام:**
  ```
  set [beats v] to (0)      ← مسح وبداية من الصفر
  change [beats v] by (1)   ← زيادة على الموجود
  ```
- **تذكير:** `set` بيمسح · `change` بيزود. الرقم السالب فى `change` بيقلل.
- **التصفير:** `set ... to 0` تحت `when green flag clicked` — من غيره الرقم بيكمل من اللعبة اللى فاتت.

### `SK-A-18` — أسأل المستخدم — `A2-S06`
- **الخطوات:** `Sensing` ← `ask [اسمك إيه؟] and wait` ← وبعده على طول `set [<اسم المتغير>] to (answer)`.
- **تذكير:** `answer` بيتغير مع كل `ask` جديد. **احفظه فى متغير فورا** وإلا هيضيع.
- **⚠️ المتغير اللى بتحفظ فيه لازم يبقى فاضى لسه:** لو المشروع فيه متغير اسمه `name` بيحمل حاجة تانية (زى اسم المحل فى `A2-S09`)، **اعمل متغير جديد** — ماتحفظش فوقه. الحفظ بيمسح اللى كان جواه.

### `SK-A-19` — أعمل طريقين — `A2-S07`
- **الخطوات:** `Control` ← `if < > then ... else ...`
  ```
  if <(beats) > (9)> then
    hide
    change [beats v] by (-10)
    broadcast (snare)
  else
    say [محتاج beats أكتر!] for (2) seconds
  ```
- **تذكير:** طريقين بس — مافيش تالت. اللى مش فى `if` بيروح `else` بالضرورة.
- **`hide` أول بلوك:** زرار الشراء بيختفى بعد ما تشترى — من غيره تقدر تشترى نفس الحاجة تانى وتالت. الترتيب ده هو اللى فى `P3-final` بالظبط.

### `SK-A-20` — أستشعر اللون — `A2-S05`
- **الخطوات:** `Sensing` ← `touching color ( )?` ← اضغط على المربع اللونى ← **القطارة** ← دوس على اللون على الستيج نفسه.
- **تذكير:** ماتخمنش اللون من المنتقى — استخدم القطارة. فرق درجة واحدة = الشرط مايتحققش أبدا.

### `SK-A-21` — أنقل سبرايت لمشروع تانى — `A2-S03`
- **متى:** عايز سبرايت عملته فى مشروع يشتغل فى مشروع تانى، أو تدى نسخة منه لزميلك.
- **الخطوات:** كليك يمين على السبرايت فى القائمة ← `export` ← يتحفظ ملف `.sprite3`.
- **الاستيراد:** فى المشروع التانى: زرار السبرايت ← `Upload Sprite` ← اختار الملف.
- **تذكير:** السبرايت بيروح **بكوده وصوته وكوستيوماته**. ده بديلنا عن `Backpack` اللى بيطلب حساب.

## مسار `B` — الويب

### `SK-B-01` — أفتح مشروعى
- **الخطوات:** `VS Code` ← `File` ← `Open Folder` ← فولدر مشروعى ← اضغط `index.html` فى الشمال. وفى المتصفح: اسحب `index.html` عليه.
- **تذكير:** عدلت؟ `Ctrl+S` فى `VS Code` ← `F5` فى المتصفح. **الاتنين.**

### `SK-B-02` — أكتب عنوان وفقرة
- **الخطوات:**
  ```
  <h1>العنوان</h1>
  <p>الفقرة</p>
  ```
- **تذكير:** كل تاج بيتقفل بـ `/`.

### `SK-B-03` — أضيف صورة
- **الخطوات:** `<img src="اسم-الصورة.png" alt="وصف الصورة">` — مالوش قفل.
- **تذكير:** الاسم بالظبط — حروف كبيرة وصغيرة فارقة. و`alt` مش اختيارى: ده اللى بيتقرا لمن مايشوفش الصورة، وبيظهر لو الصورة ماتحملتش.

### `SK-B-04` — أعمل قائمة
- **الخطوات:** `<ol>` لما الترتيب مهم (بترقم لوحدها) · `<ul>` لما مش مهم (نقط).
  ```
  <ol>
    <li>الأول</li>
    <li>التانى</li>
  </ol>
  ```
- **تذكير:** `<ol>` بدل `<ul>` = أرقام.

### `SK-B-05` — أغير لون أو حجم
- **الخطوات:** فى ملف `CSS`:
  ```
  h1 {
    color: purple;
    font-size: 50px;
  }
  ```
- **تذكير:** `color` مش `colour`. فاصلة منقوطة بعد كل سطر.

### `SK-B-06` — أستخدم كلاس
- **الخطوات:** فى `HTML`: `<p class="big">`. فى `CSS`: `.big { font-size: 40px; }`.
- **تذكير:** النقطة قبل اسم الكلاس فى `CSS` بس.

### `SK-B-07` — أضيف مسافة
- **الخطوات:** `padding: 20px;` = جوه. `margin: 20px;` = بره.

### `SK-B-08` — أعمل هوفر
- **الخطوات:**
  ```
  .card:hover {
    transform: scale(1.2);
  }
  ```
- **تذكير:** `1.2` يعنى يكبر `20%`. الرقم ده هو اللى فى `style.css` بتاع المشروع بالظبط — قارن.

### `SK-B-09` — أضيف خط من `Google Fonts`
- **الخطوات:** موقع `fonts.google.com` ← اختار الخط ← انسخ سطر `<link>` وحطه فى `<head>` ← بعدين غير اسم الخط فى `CSS`.
- **فى مشروع الكارت:** الاسم بيتغير جوه المتغير فى `default.css` — مش سطر `font-family` مستقل.
  ```
  --title-font: lighter 2rem Bangers, cursive;
  ```
  الترتيب: السمك ← الحجم ← اسم الخط ← الخط الاحتياطى.
- **تذكير:** محتاج نت. لو مافيش، سيب الترتيب زى ما هو وبدل اسم الخط بـ `Impact` — خط موجود على الجهاز.

### `SK-B-10` — أعمل تدرج
- **الخطوات:** `background: linear-gradient(purple, orange);`

### `SK-B-11` — أعمل أنيميشن
- **الخطوات:** نفس الصيغة اللى فى `animation.css` بتاع المشروع بالظبط — `0%` و`100%` مش `from`/`to`.
  ```
  @keyframes rotate-center {
    0%   { transform: rotate(0); }
    100% { transform: rotate(360deg); }
  }
  .spinme { animation: rotate-center linear 8s 2; }
  ```
- **الترتيب:** الاسم ← نوع السرعة ← المدة ← عدد المرات.
- **تذكير:** `infinite` بدل الرقم = مايقفش. و`display: inline-block` لازمة عشان العنصر مايتقسمش على سطر جديد.

### `SK-B-12` — أضيف لينك
- **الخطوات:** `<a href="page2.html">الصفحة التانية</a>`

### `SK-B-13` — ألاقى الغلط
- **الخطوات:** `1` كل تاج مقفول؟ `2` `F12` — فيه حاجة حمرا؟ `3` الاسم بالظبط (صورة، كلاس، ملف)؟ `4` الفاصلة المنقوطة والأقواس فى `CSS`؟ `5` حفظت؟ عملت `F5`؟

### `SK-B-14` — أرفع على `GitHub`
- **الخطوات:** الريبو ← `Add file` ← `Upload files` ← اسحب ← `Commit changes`.
- **تذكير:** الملف الرئيسى اسمه `index.html` بالظبط.

### `SK-B-15` — أعدل على `GitHub`
- **الخطوات:** افتح الملف ← القلم ✏️ ← عدل أو الصق ← اكتب وصف ← `Commit changes` ← استنى دقيقة ← `refresh`.

## قواعد البطاقات

- توزع البطاقات **تدريجيا** — كل جلسة بطاقاتها الجديدة. الطفل مايستلمش `14` بطاقة يوم واحد.
- الطفل بيجمعها فى حلقة على الترابيزة. آخر المستوى تروح معاه البيت.
- المدرس يقول «بص فى البطاقة» قبل ما يجاوب.
- الصور لكل بطاقة فى `assets/cards/` — لقطات حقيقية بالزرار محوط.
