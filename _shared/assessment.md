## 2. التشخيص — `S01`

**الغرض الوحيد: تكوين أزواج متقاربة.** لا درجة، لا فرز.

### 2.1 النشاط — `15` دقيقة

بطاقات مطبوعة، كل طفل لوحده:

| الجزء | البطاقات | المطلوب |
| --- | --- | --- |
| أ — `5` دقائق | `6` بطاقات خطوات «عمل ساندويتش» مبعثرة | رتبها |

| ج — `3` دقائق | تسلسل مرتب فيه خطوة غلط | لاقى الغلط |

### 2.2 قائمة المراقبة — للمدرس

| المؤشر | ✓ / ✗ |
| --- | --- |
| رتب (أ) صح بدون مساعدة | |
| استخدم بطاقة «كرر» فى (ب) | |
| لاقى الغلط فى (ج) | |
| اشتغل مستقلا بدون ما يبص لجاره | |

**تكوين الأزواج:** `4` ✓ مع `3–4` ✓ · `2` ✓ مع `1–2` ✓ · `0` ✓ مع `1` ✓. الطفل بـ `0` **لا** يتزاوج مع `4`.

### 2.3 تشخيص `A2-S01` — نسخة مختلفة

الأطفال دول خلصوا `A1` فعلا، فالتشخيص مش «هل يعرف يرتب؟» — التشخيص هو **إيه اللى فضل معاه من `A1`**. النشاط `Parsons` على الجهاز مش بطاقات ورق، والمؤشرات خمسة:

| المؤشر | يتقاس بـ | ✓ / ✗ |
| --- | --- | --- |
| التسلسل | رتب `PS-A-01` صح من أول مرة | |
| الإيفنت | اختار الإيفنت الصح فى `PS-A-03` | |
| اللوب | حط البلوك جوه اللوب مش برة فى `PS-A-07` | |

**تكوين الأزواج:** نفس القاعدة — المتقارب مع المتقارب، والطفل بمؤشر واحد **لا** يتزاوج مع طفل بخمسة.

## 3. الـ `Rubric` — نهاية المستوى

مبنى على `Brennan & Resnick`: مفاهيم · ممارسات · منظورات. أربعة مستويات، لا أرقام ولا درجات للطفل — الأرقام للمدرس فقط.

### 3.1 مسار `A1`

| البعد | `1` بيبدأ | `2` بيتعلم | `3` بيطبق | `4` بيعلم غيره |
| --- | --- | --- | --- | --- |
| **التسلسل** | يرتب بمساعدة | يرتب `3–4` بلوكات | يبنى سكربت كامل | يشرح ليه الترتيب مهم |
| **الأحداث** | يعرف العلم الأخضر | يستخدم إيفنتين | يختار الإيفنت المناسب | يشرح الفرق بينهم |
| **اللوب** | يعرف شكله | يستخدم `repeat` | يختار بين `repeat` و`forever` | يشرح إمتى نستخدم كل واحد |
| **التصحيح** | يلاحظ إن فيه غلط | يلاقيه بمساعدة | يلاقيه ويصلحه | يشرح إزاى لاقاه |
| **الشرح** | يشاور على الشاشة | يوصف اللى عمله | يشرح ليه عمله كده | يقترح تطويرا |
| **الاستقلال** | يحتاج توجيها مستمرا | يحتاج تلميحا | يشتغل مستقلا | يساعد غيره |

### 3.2 مسار `A2`

`A2` بيدى تلات حاجات جديدة — التواصل والقرار والذاكرة. الـ `rubric` بيقيسهم هما، مش بيعيد قياس `A1`.

| البعد | `1` بيبدأ | `2` بيتعلم | `3` بيطبق | `4` بيعلم غيره |
| --- | --- | --- | --- | --- |
| **الرسالة** | يعرف إن فيه بلوك بيبعت | يبعت رسالة ويستقبلها فى سبرايت تانى | يخلى **أكتر من سبرايت** يرد على نفس الرسالة | يشرح ليه الرسالة أحسن من إن كل سبرايت يراقب لوحده |
| **الشرط** | يعرف إن الفتحة سداسية معناها سؤال | يكتب `if` بشرط جاهز | يختار الشرط المناسب ويحطه جوه `forever` | يشرح ليه ترتيب الشرطين بيغير النتيجة |
| **المتغير** | يعرف إن فيه صندوق ليه اسم | يعمل متغير ويعرضه | يفرق بين `set` و`change` ويصفر عند البداية | يشرح الفرق بمثال من عنده |
| **المحاكاة** | يخلى حاجة تتحرك | يخلى متغير يتغير بضغطة المستخدم | يخلى المتغير **يتغير لوحده** مع الوقت | يربط تغير المتغير بسلوك السبرايت بشرط |
| **التصحيح** | يلاحظ إن فيه غلط | يلاقيه بمساعدة | يستخدم `SK-A-14` ويلاقيه | يشرح إزاى لاقاه |
| **الاستقلال** | توجيه مستمر | تلميح | مستقل | يساعد غيره |

### 3.3 مسار `B1`

| البعد | `1` بيبدأ | `2` بيتعلم | `3` بيطبق | `4` بيعلم غيره |

## 4. المقابلة حول المنتج — `5` دقائق مصورة

**الإعداد:** ركن هادى، الكاميرا على الشاشة والطفل، المشروع مفتوح.

| الدقيقة | السؤال | يقيس |
| --- | --- | --- |
| `0–1` | «ورينى مشروعك. بيعمل إيه؟» | الشرح |
| `1–2` | «اختار حتة من الكود واشرحهالى» | المفاهيم |
| `2–3` | «إيه أصعب حاجة قابلتك؟ وحليتها إزاى؟» | التصحيح والممارسات |
| `3–4` | «لو عندك ساعة كمان، هتضيف إيه؟» | المنظورات |
| `4–5` | سيناريو — **بيختلف بالمسار** (تحت) | النقل |

**سؤال السيناريو — حسب المستوى، مش حسب المسار:**

> ⚠️ **«نسخة مسار `A`» مش وصف كافى.** `A1` و`A2` الاتنين مسار `A` وسؤالهم مختلف تماما. أى ملف جلسة بيقول «نسخة مسار `A`» بيخلى المدرس ياخد سؤال `A1` لطفل `A2` — والبعدان اللى `rubric` `A2` قايم عليهما (الرسالة والمحاكاة) مايتقاسوش. **اكتب اسم المستوى صريحا.**

| المستوى | السؤال |
| --- | --- |
| `A1` — `Scratch` | «لو عايز السبرايت يتكلم لما نضغط عليه بدل العلم، هتغير إيه؟» |
| `A2` — `Scratch` | «لو عايز **سبرايت تانى كمان** يرد على نفس الرسالة — هتعمل إيه؟ وبعدين: لو عايز المتغير يقل لوحده كل `5` ثوانى؟» |
| `B1` — ويب | «لو عايز نفس الصفحة بلوحة ألوان تانية — هتغير فين؟ وبعدين: لو عايز تضيف صفحة تانية وتوصلها بالأولى؟» |

السبب: السؤال بيقيس **نقل المفهوم**، فلازم يكون من عالم الطفل نفسه. طالب `B1` عمره ما فتح `Scratch`.

**قواعد:** المدرس لا يصحح أثناء المقابلة. يسمع ويسأل «ليه؟». لو الطفل سكت `10` ثوان، يعيد السؤال بصيغة أبسط.

**الأطفال بلا موافقة تصوير:** نفس المقابلة، المدرس يكتب الملاحظات فى ورقة الـ `rubric`.
