## 1. لماذا `GitHub Pages`

مخرج `B1` صفحة ويب. نشرها على `GitHub Pages` مجانى، وبيدى فى خطوة واحدة:
- حساب `GitHub` حقيقى — بداية `portfolio`
- أول `commits` — الطفل يعيش الدورة: تعديل ← `commit` ← الموقع اتحدث
- **رابط شغال** — ولى الأمر يفتحه من موبايله

## 4. `S12` — أول `repo` والنشر — بلوك المهارة `15` دقيقة

**فولدر `images/` ماينفعش يترفع** — `19MB` و`38` صورة مش مستخدمة، هيوقف الرفع على نت المدرسة.
**كام رابط النهاردة؟** `6` — ريبو **السائق** فى كل زوج. ريبو الملاح فى أول `10` دقايق من `S13`. الوقت المتاح مايكفيش `12` تسجيل دخول ورفع وتفعيل على `6` أجهزة.

**قبل البلوك:** المدرس راجع محتوى صفحة كل طفل بقائمة فحص `safeguarding.md` §1.2 ووقع.

| الدقيقة | الخطوة | الشريحة |
| --- | --- | --- |
| `0–2` | تسجيل الدخول. من غير حساب؟ يتابع على شاشة زميله | — |
| `2–5` | `New repository` ← الاسم: اسم المشروع مش اسم الطفل ← `Public` ← `Create` | لقطة حقيقية |
| `5–9` | `Add file` ← `Upload files` ← يسحب **`4` ملفات + فولدر واحد**: `index.html` · `style.css` · `animation.css` · `default.css` · **وفولدر `palettes` كله بالسحب** ← `Commit changes` | لقطة حقيقية |
| `9–13` | `Settings` ← `Pages` ← `Branch: main` ← `Save` | لقطة حقيقية |
| `13–15` | الرابط يظهر: `username.github.io/repo-name` — يكتبه فى الدفتر. **الموقع بياخد دقيقة أو اتنين يظهر** — نفتحه فى الجلسة الجاية | — |

**المصطلحات الجديدة:** `G-232` `repository` · `G-233` `commit` · `G-234` `GitHub Pages`

## 5. `S14` — رفع ثم `commit` تعديل

الجلسة فيها **`commit`ان**، مش واحد. السبب: كل شغل `S13` محلى وماترفعش، فالرابط الحى لسه هيكل `S12` الفاضى — والزائر والمقابلة المصورة الاتنين على الرابط. فلازم الرفع يسبق الزيارة.

**بناء `1` — الرفع قبل الزائر**

| الدقيقة | الخطوة |
| --- | --- |
| `3–6` | المدرس يراجع محتوى كل صفحة بقائمة `safeguarding.md` §1.2 ويوقع. **اللى مش موقع مايعملش `commit`** |
| `6–9` | رفع شغل `S13` كله: `Add file` ← `Upload files` ← `Commit changes` |
| `10–20` | الزائر يفتح الرابط الحى — وده بقى فيه شغل حقيقى |

**بلوك المهارة — `commit` التعديل**

| الدقيقة | الخطوة |
| --- | --- |
| `0–2` | عدل حاجة واضحة فى `index.html` على جهازك — لون العنوان مثلا |
| `2–8` | فى `GitHub`: افتح `index.html` ← أيقونة القلم ← الصق الملف الجديد ← `Commit changes` مع وصف: «غيرت لون العنوان» |
| `8–12` | استنى دقيقة. `refresh` على الرابط. اتغير؟ |
| `12–15` | الدفتر: «الدورة: عدلت ← `commit` ← الموقع اتحدث» |

**الختام يبدأ بـ `Sign out`** — بند إلزامى فى نشرة ولى الأمر (§3).

**الدرس الأساسى:** الموقع مش حاجة بتتعمل مرة واحدة. بيتعدل وبيتحدث. ده اللى المبرمجين بيعملوه كل يوم.

## 7. طفل تحت `13` أو بلا حساب

**الأكاديمية تملك `GitHub organization`** اسمه `El-Madina-4U` — ده الاسم الظاهر فى كل لقطات `B-GH-*`.

- المدرس ينشئ الريبو تحت الـ `organization` باسم المشروع.
- الطفل يعمل نفس خطوات التعديل على ملفه المحلى.
- المدرس يرفع الملف بحسابه. الطفل يشوف نفس الرابط ونفس الدورة.
- عند بلوغ `13` وإنشاء حساب: الريبو ينقل له (`Transfer ownership`).

**لا يحرم أى طفل من رابط حى بسبب السن.**
